# OpenLegend

OpenLegend 是《金庸群侠传》DOS 版的 C++ 重写。剧情、战斗、数值、画面与操作以原版 Z.COM／Z.DAT 的机器码和原版资源为准复现，并在此基础上增加下列功能。

仓库不包含、也不分发原版游戏数据。使用者须自行合法取得原版资源。

## 功能

### 与原版的关系

- 剧情、战斗规则、人物数值、随机数与游戏节奏按原版实现；
- 画面、文字、音乐与音效读取玩家提供的原版资源；
- 游戏画面按像素放大，不做平滑缩放；
- 与原版不同的行为在下文“规则调整与修正”中列出。

### 存档

- 最多 999 个存档槽位；
- 存档列表显示主角姓名、等级和最近地点；
- 支持翻页、跳到首尾槽位、删除存档，损坏的存档会标出；
- 存档目录可与游戏数据目录分开；
- 标题界面、游戏菜单和死亡界面使用同一个存档列表。

### 姓名输入

- 默认使用原版内建的注音／英数输入；
- `[input].name_entry = "modern"` 改用 SDL／系统输入法及其候选窗口；
- 姓名画面按 F12 在两种输入方式间切换，只对当前会话有效，不改写配置；
- 系统输入法提交的 UTF-8 姓名转换为 CP950/Big5，长度不超过原存档的 6 字节。

### 画面与分辨率

- 游戏画面的宽高可调大，地图显示范围随之扩大，地图格、人物和物件的像素大小不变；
- 菜单、对话框和状态信息随游戏画面等比缩放，宽高比不同时居中并留黑边；
- 存档列表、地点提示和坐标按窗口实际分辨率绘制；
- 世界地图常驻显示坐标，场景中常驻显示地点名称和坐标。

### 操作

- 世界地图与场景按连续坐标移动；`[input].smooth_movement = false` 恢复原版逐格移动；
- 长按方向键连续行走，转向时不重新等待长按延迟；
- 菜单、商店、战斗选项和存档列表支持方向键连发；
- 战斗中同时按住多个方向键时，光标的连续移动方向不变；
- 移动与菜单的长按延迟分别设置；
- 自动战斗中按空格、回车或 Esc 取消自动；
- 物品列表按 PageUp／PageDown 整页翻动。

### 多周目（New Game+）

- 默认关闭，`[new_game_plus].enabled = true` 开启；
- 开启后存档格式为 TOML；通关后可保存通关进度，在标题界面选择 New Game+ 进入下一周目；
- 人物、武功、物品按规则继承，敌人属性按周目增加；
- 规则见 [NG+ 设计文档](docs/new-game-plus-design.zh-Hans.html)。

### 战斗界面

- 中央行动面板固定列出 10 个行动，不可用的灰显；数字键 1～9、0（含小键盘）对应固定的行动；
- 画面左侧纵向显示本回合行动顺序，当前行动者黄框，我方蓝框、敌方红框；
- 底部信息条显示当前行动者的生命、内力、体力与状态；右上角信息卡显示光标所指角色，敌方行动时显示该敌方；
- 施展武功时画面顶部显示“武功名 N級”；
- 选择武功施放位置时，地面标出覆盖范围；
- 面板使用原版圆角框。

### 世界地图

- M 或 Tab 打开全屏世界地图，按键由 `[input].world_map_keys` 设定；
- 打开时以人物为中心，方向键平移，可缩放；
- 标出离视野中心最近的有名字地点；在大地图上按 Enter 或空格传送到该地点入口旁；
- 罗盘说明栏显示韦小宝所在的客栈。

### 状态与物品界面

- 状态页分为狀態、能力、武功三个页签，内容在框内水平居中；
- 武功页签列出等级、熟练度、当前等级威力和武功带毒值；
- 队伍人数超过一屏时人物列表滚动；战斗中查看状态时长按方向键连续切换人物；
- 物品页增加“天書”页签，列出十四天书（物品 144～157）；
- 医疗、解毒选择对象时使用列表，显示姓名、生命和内伤。

### 规则调整与修正

- 30 级以后每级所需经验按原版经验表每级费用的拟合倍率（约 1.15）递增；
- 一场战斗中，同一敌人计入攻击经验的累计伤害不超过其最大生命；
- 药品回生命、回内力按目标最大值的比例生效：原版回复量 × 目标最大值 ÷ 999（999 为原版生命与内力上限，读自 Z.DAT）。生命仍保留原版的随机 0～9 与内伤折扣，内力与原版一样没有随机数；物品栏把正的生命值、内力值加成显示为百分比；
- 原版在解毒、医疗、用毒时会播放最近选用的武功音效；此处已去掉该音效，只播放效果音。

### 合战规则

- `openlegend.toml` 同目录下的 `battle_merges.toml` 可让一场剧情战斗并入另一场战斗的敌人，并在开战前插播对白；
- 每条规则列出所依赖资源文件的 SHA-256，不符时该条规则不生效；敌方槽位或站位不足时本场按原版进行；
- 附带的规则：NG+ 中主角道德为 0 时，最终战十大善人与十大恶人同场出战。见 [`config/battle_merges.toml`](config/battle_merges.toml)。

### 运行设置

- 可设置游戏数据目录、存档目录、游戏画面大小、窗口大小和启动时是否最大化；
- 可设置移动长按延迟、菜单连发速度和淡入淡出速度；
- 每次启动可生成单独的日志文件；
- 游戏闲置时降低 CPU 占用。

具体设置方法见 [`config/openlegend.example.toml`](config/openlegend.example.toml)。
