# OpenLegend

OpenLegend 是《金庸群侠传》DOS 版的 C++ 重写。剧情、战斗、数值、画面与操作以原版 Z.COM／Z.DAT 的机器码和原版资源为准复现，并在此基础上增加下列功能。

主页：<https://ouroboros.github.io/OpenLegend/>

仓库不包含、也不分发原版游戏数据。使用者须自行合法取得原版资源。

## 使用方法

### 准备

1. 准备《金庸群侠传》DOS 版的完整游戏目录（含 `Z.COM`、`Z.DAT`、`RANGER.GRP`、`ALLSIN.GRP` 等原版文件）。
2. 从 [Releases](https://github.com/Ouroboros/OpenLegend/releases) 下载 `OpenLegend-<版本>-windows-x64.zip`，解压得到：

   | 文件 | 用途 |
   |---|---|
   | `openlegend.exe` | 游戏程序 |
   | `openlegend.toml` | 界面与操作设置，并指定使用哪个 MOD 配置 |
   | `mods\original.toml` | 原版的 MOD 配置：数据目录、存档目录、多周目设置 |
   | `mods\canglongzhuri.toml` | 苍龙逐日的 MOD 配置 |

3. 在 `openlegend.toml` 中指定原版的 MOD 配置：

   ```toml
   [paths]
   mod = './mods/original.toml'
   ```

4. 在 `mods/original.toml` 的 `[paths]` 中写明原版游戏目录和存档目录：

   ```toml
   [paths]
   data_dir = 'D:\Games\金庸群侠传'
   save_dir = './save/original'
   ```

5. 双击 `openlegend.exe` 运行。

### 配置

手动设置修改后重启游戏生效：

| 文件 | 职责 | 程序读写 |
|---|---|---|
| `openlegend.toml` | 用户设置：界面、操作和使用哪个 MOD | 只读，保留注释和顺序 |
| `openlegend.default.toml` | 程序记忆：窗口状态、各 MOD 的上次存档槽 | 自动生成并写回 |
| MOD 配置，如 `mods/original.toml` | 数据目录、存档目录、多周目、合战规则、资源文件名 | 只读 |

主配置读取优先级为：代码默认值 → `openlegend.default.toml` → `openlegend.toml`，同名项以后者为准，子表逐字段合并。

`openlegend.default.toml` 放在 exe 旁，首次启动时生成，不随发布包分发。值没有变化时不写文件，写回时先生成临时文件再替换原文件。文件格式错误时启动报错，原文件不会被覆盖。

用户文件中明确填写的项，每次启动都会覆盖程序记忆。希望自动记忆的项应保持注释；旧配置中固定的窗口值也需要注释掉，才能恢复上次窗口状态。

所有相对路径都以 `openlegend.exe` 所在目录为基准。

#### openlegend.toml

```toml
[paths]
# 使用哪个 MOD 配置。不写时使用程序内置的原版设定（数据为启动目录，存档写入数据目录，
# 不开启多周目、无合战规则）。本文件不接受 data_dir、save_dir、[new_game_plus]、[saves]。
mod = './mods/original.toml'

[logging]
# 日志文件前缀，每次启动在其旁生成 PREFIX-日期-时间-PID.log；不写时为 logs/<exe 名>。
# path = 'logs/openlegend.log'
# 级别：trace、debug、info、warning、error、critical。
level = 'info'

[input]
# 姓名输入方式："legacy" 为原版注音键盘，"modern" 为系统输入法；姓名画面按 F12 临时切换。
name_entry = 'modern'
# 平滑移动；false 恢复原版逐格移动，移动速度不变。
smooth_movement = true
# 按住方向键到开始连续移动的延迟（毫秒），0 为立即。
movement_repeat_delay_ms = 200
# 菜单按住方向键到开始连发的延迟，以及连发间隔（毫秒）。
menu_repeat_delay_ms = 500
menu_repeat_interval_ms = 55
# 打开／关闭全屏世界地图的按键，可写多个：A～Z、0～9、Tab、F1～F10。
world_map_keys = ['M', 'Tab']

[timing]
# 淡入淡出每帧的延迟（毫秒），原版 VGA 为 14.268，0 为不等待。
fade_frame_delay_ms = 5

[window]
# 窗口还原时的大小，以及启动时是否最大化；画面保持宽高比，比例不同时留黑边。
# 保持注释时使用程序记忆；取消注释会固定该项，优先于上次保存的窗口状态。
# width = 960
# height = 600
# maximized = false

[display]
# 游戏画面的逻辑分辨率：scale 为 320×200 的倍数（1.0～4.0），优先于 width、height。
# 调大后地图显示范围变大，地图格与人物的像素大小不变。
scale = 2
# 不用 scale 时直接写宽高（320～1280 × 200～800），两项须同时写。
# width = 640
# height = 400
```

#### openlegend.default.toml

由程序生成和维护，不需要手写。下面展示窗口状态及两套 MOD 各自的槽位记忆，槽位编号从 0 开始：

```toml
[window]
# 退出时保存的窗口大小。
width = 960
height = 600
# 退出时是否最大化。
maximized = false

[mods.'mods/original.toml']
# 原版 MOD 上次使用的存档槽。
last_slot = 0

[mods.'mods/canglongzhuri.toml']
# 苍龙逐日上次使用的存档槽，与原版分别记忆。
last_slot = 2
```

MOD 记录使用相对于 exe 的配置路径作为键。旧 MOD 配置中的 `[saves] last_slot` 会在程序文件尚无该 MOD 的记录时导入一次，旧文件保持原样。

#### MOD 配置

```toml
format = 1                       # 格式版本，必须为 1
name = '金庸群侠传（原版）'       # 显示在窗口标题，并写入日志

[paths]
# 原版或 MOD 的数据目录；不写时为启动时的当前目录。
data_dir = 'D:\Games\金庸群侠传'
# 存档目录；不写时为 save/<本文件名去掉扩展名>，不同 MOD 的存档自然分开。
save_dir = './save/original'

[new_game_plus]
# 多周目开关；不写这一节时不开启。开启后存档为 TOML，通关后可在标题选 New Game+。
enabled = true
# 最大周目序号。
maximum_playthroughs = 999
# 敌人每多一个周目增加的量：最大生命、最大内力、攻击、防御、用毒、抗毒、暗器、等级。
hp_cap_step = 999
mp_cap_step = 999
attack_cap_step = 100
defence_cap_step = 100
use_poison_cap_step = 100
anti_poison_cap_step = 100
hidden_weapon_cap_step = 100
role_level_step = 30
# 敌人已学武功每周目增加的等级（1 级 = 100 熟练度）。
martial_level_step = 10
# 战斗经验倍率（%）：第 2 周目，以及之后每周目再加的百分点（250%、350%……）。
battle_experience_percent_ng2 = 150
battle_experience_percent_step = 100

# 合战规则，可写多条，按顺序取第一条满足条件的。
# 剧情开战 battle 时，若满足条件，先播放 dialogues，再把 merge_battle 的敌人并入本战。
[[merge]]
battle = 134                     # 触发的战斗编号（WAR.STA）
merge_battle = 133               # 要并入敌人的战斗编号
new_game_plus_only = true        # 只在开启多周目时生效
role = 0                         # 检查道德的角色编号，0 为主角
morality_min = 0                 # 道德下限（含）
morality_max = 0                 # 道德上限（含）
# 开战前插播的对白：[对白编号, 头像编号, 样式]，样式 0 为对方说话、1 为主角说话。
dialogues = [[2919, 67, 0], [2920, 71, 0], [2921, 0, 1]]

# 这条规则依赖的资源文件（相对 data_dir）及 SHA-256，必填；任一不符时只停用这一条。
[merge.assets]
'KDEF.GRP' = '135c5e09…'
'TALK.GRP' = '5cde1186…'
'WAR.STA' = '98e3f669…'

[files]
# 按编号打开的资源文件名表，第 n 项为编号 n 的文件名（相对 data_dir），只有改过
# Z.DAT 文件名表的 MOD 才需要；不写的表使用原版命名，编号超出所列项数时报错。
scene_sprite_index = ['sdx', 'sdx']        # 场景贴图索引，原版 SDXnnn
scene_sprite_group = ['smp', 'smp']        # 场景贴图，原版 SMPnnn
battlefield_index = ['wdx', 'wdx']         # 战场贴图索引，原版 WDXnnn
battlefield_group = ['wmp', 'wmp']         # 战场贴图，原版 WMPnnn
fight_index = ['fdx000', 'fdx001']         # 战斗动画索引，原版 FIGHTnnn.IDX
fight_group = ['fmp000', 'fmp001']         # 战斗动画，原版 FIGHTnnn.GRP
```

除 `format`、`name` 外各节都可省略；出现未知字段或取值不合法时启动报错。现成的配置见 [`config/mods/`](config/mods/)：原版 [`original.toml`](config/mods/original.toml)，苍龙逐日 [`canglongzhuri.toml`](config/mods/canglongzhuri.toml)（`[files]` 取自其 `Z.DAT`）。人物、物品、场景等记录数量和对话条数按数据文件读取；MOD 在 `Z.DAT` 中修改的战斗、成长等规则不生效，游戏按本项目的规则运行。

### 日志

每次启动在 `openlegend.exe` 旁的 `logs\` 目录生成一个日志文件。启动失败或出错时，提示信息和日志会写明原因。

## 功能

### 与原版的关系

- 剧情、战斗规则、人物数值、随机数与游戏节奏按原版实现；
- 画面、文字、音乐与音效读取玩家提供的原版资源；
- 游戏画面按像素放大，不做平滑缩放；
- 与原版不同的行为在下文“规则调整与修正”中列出。

### 存档

- 最多 999 个存档槽位；
- 存档列表显示主角姓名、等级和最近地点；
- 支持翻页、跳到首尾槽位和删除存档；
- 损坏的存档会标出；
- 存档目录可与游戏数据目录分开；
- 标题界面、游戏菜单和死亡界面使用同一个存档列表。

### 姓名输入

- 默认使用原版内建的注音／英数输入；
- `[input].name_entry = "modern"` 改用 SDL／系统输入法及其候选窗口；
- 姓名画面按 F12 在两种输入方式间切换，只对当前会话有效，不改写配置；
- 系统输入法提交的 UTF-8 姓名转换为 CP950/Big5，长度不超过原存档的 6 字节。

### 画面与分辨率

- 游戏画面的宽高可调大，地图显示范围随之扩大，地图格、人物和物件的像素大小不变；
- 菜单、对话框和状态信息随游戏画面等比缩放，宽高比不同时居中并留黑边；
- 存档列表、地点提示和坐标按窗口实际分辨率绘制；
- 世界地图常驻显示坐标，场景中常驻显示地点名称和坐标。

### 操作

- 世界地图与场景按连续坐标移动；
- 设置 `[input].smooth_movement = false` 可恢复原版逐格移动；
- 长按方向键连续行走，转向时不重新等待长按延迟；
- 菜单、商店、战斗选项和存档列表支持方向键连发；
- 战斗中同时按住多个方向键时，光标的连续移动方向不变；
- 移动与菜单的长按延迟分别设置；
- 自动战斗中按空格、回车或 Esc 取消自动；
- 物品列表按 PageUp／PageDown 整页翻动。

### 多周目（New Game+）

- 默认关闭，在 MOD 配置的 `[new_game_plus]` 中写 `enabled = true` 开启（原版使用 `mods/original.toml`）；
- 开启后存档格式为 TOML；
- 通关后可保存通关进度，在标题界面选择 New Game+ 进入下一周目；
- 人物、武功、物品按规则继承到下一周目，左右互搏也一并继承；
- 敌人每多一个周目按下表增长，当前生命和内力随最大值同步增加；
- 数值都可在 MOD 配置的 `[new_game_plus]` 中设置：

  | 属性 | 每周目增加 | 配置项 |
  |---|---|---|
  | 最大生命 | +999 | `hp_cap_step` |
  | 最大内力 | +999 | `mp_cap_step` |
  | 攻击 | +100 | `attack_cap_step` |
  | 防御 | +100 | `defence_cap_step` |
  | 用毒 | +100 | `use_poison_cap_step` |
  | 抗毒 | +100 | `anti_poison_cap_step` |
  | 暗器技巧 | +100 | `hidden_weapon_cap_step` |
  | 等级 | +30 | `role_level_step` |
  | 已学武功 | +10 级 | `martial_level_step` |

- 战斗经验倍率（`battle_experience_percent_ng2`、`battle_experience_percent_step`）：

  | 周目 | 1 | 2 | 3 | 4 | 5 |
  |---|---|---|---|---|---|
  | 经验倍率 | 100% | 150% | 250% | 350% | 450% |

- 装备的攻击、防御加成乘以周目数，轻功加成不乘；
- 武器与对应武功搭配时的额外攻击加成，第 n 周目另加 n 倍；
- 人物的等级、属性、武功熟练度不按周目封顶；
- 轻功、拳掌、御剑、耍刀仍最高 100；
- 详细规则见 [NG+ 设计文档](docs/new-game-plus-design.zh-Hans.html)。

### 战斗界面

- 中央行动面板固定列出 10 个行动，不可用的灰显；
- 数字键 1～9、0（含小键盘）对应固定的行动；
- 画面左侧纵向显示本回合行动顺序，当前行动者黄框，我方蓝框、敌方红框；
- 底部信息条显示当前行动者的生命、内力、体力与状态；
- 右上角信息卡显示光标所指角色，敌方行动时显示该敌方；
- 施展武功时画面顶部显示“武功名 N級”；
- 选择武功施放位置时，地面标出覆盖范围；
- 面板使用原版圆角框。

### 世界地图

- M 或 Tab 打开全屏世界地图，按键由 `[input].world_map_keys` 设定；
- 打开时以人物为中心，方向键平移，可缩放；
- 标出离视野中心最近的有名字地点；
- 在大地图上按 Enter 或空格传送到该地点入口旁；
- 罗盘说明栏显示韦小宝所在的客栈。

### 状态与物品界面

- 状态页分为狀態、能力、武功三个页签；
- 页签内容在框内水平居中；
- 武功页签列出等级、熟练度、当前等级威力和武功带毒值；
- 队伍人数超过一屏时人物列表滚动；
- 战斗中查看状态时长按方向键连续切换人物；
- 物品页增加“天書”页签，列出十四天书（物品 144～157）；
- 医疗、解毒选择对象时使用列表，显示姓名、生命和内伤。

### 规则调整与修正

以下改动不论是否开启 NG+ 都生效。

**等级与经验**

- 30 级以后可以继续升级，每级所需经验约比上一级多 15%（按原版经验表的增长倍率外推）；
- 一场战斗中，打同一个敌人计入经验的伤害，累计不超过它的最大生命。

**武功**

- 武功 10 级以后可以继续升级；
- 11 级起，威力和增减内力的效果按这门武功原版 1～10 级的强度继续增长；
- 11 级起，攻击范围保持 10 级时的样子；
- 武功带毒造成的中毒，按“武功带毒值 × 武功等级”计算（再加上人物自身的功夫带毒）。

**内伤**

- 内伤范围固定为 0～99；
- 受伤时增加的内伤取决于这次伤害占自身“最大生命 + 最大内力”的比例，生命和内力越高越不容易受内伤：

  | 一次伤害占（最大生命 + 最大内力） | 10% | 25% | 50% | 100% |
  |---|---|---|---|---|
  | 武功造成的内伤增加 | +4 | +12 | +24 | +49 |
  | 暗器造成的内伤增加 | +12 | +30 | +61 | +99 |

- 内伤每回合扣血，比例见下表；
- 攻击有内伤的目标时，按同样的比例额外加伤害：

  | 内伤 | 20 | 50 | 80 | 99 |
  |---|---|---|---|---|
  | 每回合扣血（占最大生命） | 1% | 2.5% | 4% | 约 5% |

**中毒**

- 中毒范围固定为 0～99；
- 每回合毒伤：

  | 中毒 | 10 | 30 | 50 | 99 |
  |---|---|---|---|---|
  | 每回合扣血（占最大生命） | 1% | 3% | 5% | 约 10% |

- 一次上毒超过对方能达到的中毒上限时，超出部分改为直接扣血；
- 每次解毒最多解除约“解毒能力 ÷ 3”（上下浮动 9 点），并且不超过 99 × 解毒能力 ÷ (解毒能力 + 100)。

**暗器**

- 伤害 = 暗器伤害值 × (暗器技巧 + 50) ÷ 50 × 内伤倍率；
- 不扣防御，不看目标的生命，没有随机数；
- 带毒暗器的上毒规则不变；
- 目标无内伤时的伤害：

  | 暗器 | 技巧 0 | 50 | 100 | 150 | 200 | 300 | 500 |
  |---|---|---|---|---|---|---|---|
  | 飛蝗石 30 | 30 | 60 | 90 | 120 | 150 | 210 | 330 |
  | 金錢鏢 35 | 35 | 70 | 105 | 140 | 175 | 245 | 385 |
  | 飛刀、毒蒺黎 40 | 40 | 80 | 120 | 160 | 200 | 280 | 440 |
  | 菩提子 45 | 45 | 90 | 135 | 180 | 225 | 315 | 495 |
  | 玉蜂針 50 | 50 | 100 | 150 | 200 | 250 | 350 | 550 |
  | 冰魄銀針 70 | 70 | 140 | 210 | 280 | 350 | 490 | 770 |
  | 金蛇錐、黑血神針 80 | 80 | 160 | 240 | 320 | 400 | 560 | 880 |
  | 霹靂彈 100 | 100 | 200 | 300 | 400 | 500 | 700 | 1100 |

- 内伤倍率沿用原版分档：

  | 目标伤势 | 无内伤 | ≤33% | ≤66% | >66% |
  |---|---|---|---|---|
  | 倍率 | 1 | 4/3 | 2 | 4 |
  | 例：霹靂彈、技巧 200 | 500 | 666 | 1000 | 2000 |

**医疗**

- 治疗量 = 医疗能力 × 倍率，最少为医疗能力的 10%；
- 回生命和治内伤用同一个治疗量，生命满时仍能治内伤：

  | 目标内伤 | 0 | 20 | 40 | 60 | 80 | 99 |
  |---|---|---|---|---|---|---|
  | 倍率 | 80% | 78% | 72% | 59% | 39% | 10% |

- 能治的条件：目标内伤不超过“医疗能力 + max(20, 医疗能力 ÷ 5)”。

**药品**

- 药品回生命、回内力 = 原版回复量 × 目标最大值 ÷ 999（999 为原版生命与内力上限，读自 Z.DAT），最多补满；
- 回生命仍保留原版的随机 0～9 与内伤折扣；
- 回内力与原版一样没有随机数；
- 物品栏把正的生命值、内力值加成显示为百分比：

  | 药品加成 | 30 | 100 | 200 | 5000 |
  |---|---|---|---|---|
  | 物品栏显示 | +3% | +10% | +20% | +100% |
  | 目标最大值 999 时回复 | 30 | 100 | 200 | 补满 |
  | 目标最大值 1998 时回复 | 60 | 200 | 400 | 补满 |

  回复量不含生命的随机 0～9 与内伤折扣。

**修正**

- 原版在解毒、医疗、用毒时会播放最近选用的武功音效，此处已去掉该音效，只播放效果音。

### 合战规则

- MOD 配置中的 `[[merge]]` 可让一场剧情战斗并入另一场战斗的敌人，并在开战前插播对白；
- 每条规则列出所依赖资源文件的 SHA-256，不符时该条规则不生效；
- 敌方槽位或站位不足时本场按原版进行；
- 附带的规则：NG+ 中主角道德为 0 时，最终战十大善人与十大恶人同场出战；
- 这条规则写在 [`config/mods/original.toml`](config/mods/original.toml) 中，使用原版 MOD 配置时生效。

### 运行设置

- 可设置游戏数据目录、存档目录、游戏画面大小、窗口大小和启动时是否最大化；
- 可通过 MOD 配置运行改动过文件名表和记录数量的 MOD 数据；
- 可设置移动长按延迟、菜单连发速度和淡入淡出速度；
- 每次启动可生成单独的日志文件；
- 游戏闲置时降低 CPU 占用。

具体设置方法见 [`config/openlegend.example.toml`](config/openlegend.example.toml)。
