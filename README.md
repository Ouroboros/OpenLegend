# OpenLegend

OpenLegend 是《金庸群侠传》DOS 版的现代重制工程，目标是在现代系统上完整保留原版的剧情、战斗、数值、画面与操作体验，同时补充更适合今天使用的界面和功能。

仓库不包含、也不会分发原版游戏数据。使用者必须自行合法取得原版资源。

## 游戏特色

### 忠于原版

- 保留原版剧情、战斗规则、人物数值、随机结果和游戏节奏；
- 使用玩家自行提供的原版画面、文字、音乐与音效资源；
- 保持原版像素风格，不用平滑缩放改变游戏画面；
- 持续根据原版程序和资源核对游戏行为。

### 现代存档管理

- 最多可以保存 999 个游戏进度；
- 存档列表显示主角姓名、等级和最近地点；
- 支持翻页、快速跳到首尾槽位、删除存档和识别损坏存档；
- 可把存档放在独立目录，避免与原版游戏资源混在一起；
- 标题界面、游戏菜单和死亡界面共用同一套存档列表。

### 现代姓名输入

- 新游戏姓名输入默认保留原版内建注音／英数方式；
- 可通过 `[input].name_entry = "modern"` 改用 SDL／系统输入法及其原生候选界面；
- 姓名画面可按 F12 在原版与现代输入间切换，只影响当前会话且不改写配置；
- 系统输入提交的 UTF-8 姓名会转换为 CP950/Big5，并遵守原存档最多 6 字节的限制。

### 更清晰的界面

- 可提高游戏画面的宽度和高度，在地图中看到更多内容，地图格、人物和物件仍保持原有像素大小；
- 菜单、对话框和状态信息会随游戏画面同比例调整，宽高比不同时居中显示并保留黑边；
- 存档列表、地点提示和坐标信息会按实际窗口大小清晰显示；
- 游戏画面仍保持原版像素效果，现代文字不会被低分辨率放大而变得模糊；
- 世界地图中常驻显示当前坐标，场景中常驻显示地点名称和当前坐标。

### 更自然的操作

- 长按方向键可以连续行走，转向时不会重新卡顿；
- 菜单、商店、战斗选项和存档列表支持稳定的方向键连发；
- 战斗中同时按下多个方向键时，光标不会突然改变连续移动方向；
- 移动与菜单的长按延迟可以分别调整；

### 可调整的运行体验

- 可设置游戏数据目录、存档目录、游戏画面大小、窗口大小和启动时是否最大化；
- 可调整移动长按延迟、菜单长按速度和画面淡入淡出速度；
- 每次启动可生成独立日志，便于定位资源、存档或运行问题；
- 游戏闲置时占用更少系统资源，减少不必要的耗电和风扇噪音。

具体设置方法见 [`config/openlegend.example.toml`](config/openlegend.example.toml)。
