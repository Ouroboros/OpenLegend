字段 poison

字段定义

poison：中毒程度。取值来源：换周目规则直接赋值。

字段中文名称下一周目值边界与说明
poison 中毒程度 0 只在换周目时清零；运行期正常上限为下方的PoisonCap(n)，并非0；NG1原版100例外保留。

原版范围与本周上限

字段NG1原版基值／有效域本周NG+上限来源默认CFG与状态
poison 正常中毒上限99；原版武功附毒恰好100例外。 运行期正常上限PoisonCap(n)来自本周CFG；换周目值另为0。 poison_cap_step=100，NG2／NG3／NG5上限199／299／499；默认配置已确认，NG2+各施毒路径的写回仍未定。

原版字段域

4.2 中毒扣血与角色解毒规则（已确认部分）

适用边界：NG1除玩家投掷带毒暗器按第4.4节改号外，其余施毒路径及中毒100例外保留原版；各周目中毒回合扣血统一读取当前中毒值，角色解毒统一读取当前真实解毒能力。

正常中毒上限由本周CFG提供，并作为本次角色解毒量的上限。

原版机器事实分列在 主动用毒、 武功附毒和 物品／投掷字段页。

各路径抗毒条件不变；NG2+其余施毒量、距离、数值域及写回边界仍未定。

本周中毒上限与跨周目回合毒伤（已确定）

正常中毒上限PoisonCap(n)的基值、CFG公式与默认配置见本字段定义。

本节只规定按目标当前中毒值结算回合扣血与角色解毒，不把NG1原版100例外改写为99，也不预先决定NG2+施毒路径的写回方式。

P = target.poison  # 本次回合状态结算读取的实际非负中毒值
PoisonHp = trunc(P ÷ 10)

中毒不是各来源分别挂上的独立回合伤害；不同施毒途径改变同一当前poison字段，符合回合状态结算资格时按现有中毒每满10点扣1点HP。

0～9扣0、50～59扣5、99扣9、100扣10；登记的默认CFG下若NG2中毒达到199，则扣19。

抗毒只在相应施毒路径中参与计算，不在每轮扣血时再次抵减。NG1原版武功附毒路径可恰好到100，解毒公式不预先把此例外改写成99。

NG2+各施毒路径如何应用本周上限及处理原版异常仍见第5.3节。

原版回合状态结算资格、顺序与HP边界

进入状态扣血分支：hurt > 0
  或 (poison > 0 且 hp > 0 且 physical_power > 0 且角色非隐藏)
HurtHp = trunc(hurt ÷ 20)
PoisonHp = trunc(poison ÷ 10)
HP1 = signed16(hp − HurtHp)
HP2 = signed16(HP1 − PoisonHp)
最终HP = (HP2 < 0) ? 1 : HP2  # 恰好0仍为0

原版每次进入回合状态结算时，先按内伤、再按中毒从HP扣除；每次写回保留有符号16位结果。

有正内伤会直接进入，即使生命、体力或隐藏条件不满足；仅由正中毒触发时，须同时满足生命与体力大于0且角色未隐藏。

原版最终HP恰好0保留0，负数反而写1。以上分支条件、16位写回及HP异常是原版事实；除已确定的跨周目毒伤trunc(P÷10)之外，不据此决定NG2+的HP边界处理。

解毒能力的原版结算、NG2+公式、随机数与算例统一见 解毒能力字段页。

原版中毒封顶的非单调异常与意图推断：主动用毒及大多数物品／暗器路径封顶99；武功附毒路径只在结果大于100时写99，恰好100保留；

原版解毒路径也只在结果大于100时写99。若原有中毒99，武功附毒理论增加1得到100，下次回合毒扣10 HP；理论增加2先得到101却改写为99，下次毒扣9 HP。

事实是原版比较条件和写回值如此；推断是它可能属于边界笔误，作者意图未经证实：目标封99应在≥100时写99， 目标封100则在>100时写100。

其他主要施毒路径封顶99使前者较符合现有规则，但不是已证实结论。NG1保留原版例外；NG2+施毒各路径如何接入CFG正常上限并处理该异常，仍属第5.3节未决。
