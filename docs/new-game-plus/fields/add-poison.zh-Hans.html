字段 add_poison

字段定义

add_poison：物品施毒／解毒值。

取值来源：当前RANGER.GRP物品定义。

换周目处理：静态物品定义不从旧库存数量推算。

该值是物品提供的毒性载荷，不等于角色use_poison或当前中毒状态。

本字段的普通物品、玩家投掷与AI投掷原版分支统一列在下方；NG1+玩家正毒技巧项改号仍归暗器技巧字段页。

玩家带毒暗器从NG1起的正毒分支技巧项改号，见 暗器技巧字段页。

物品跨周目数量筛选另见 库存数量字段页。

物品毒值：普通物品与玩家／AI暗器路径

物品与暗器的三条独立中毒路径（原版事实）

设V=item.add_poison、W=actor.hidden_weapon、A=target.anti_poison、P=target.poison。

trunc始终向零取整，负值不能改用向下取整；R1、R2是中毒分支先后取得的两个RNG.bounded(5)（各0～4）， signed16表示取低16位再按有符号数解释。

下列简式用于正常合法数值域；写回时仍按原版16位回绕与路径专属clamp处理，不得外推为NG+数值域。

普通物品效果（战斗使用物品／非战斗物品／AI普通物品）：
  V > 0：x = trunc((W + V) / 2) − A
         Δ = (A ≥ 100 或 x < 0) ? 0 : trunc(x / 2)
  V < 0：Δ = trunc(V / 2) + R1 − R2
  V = 0：跳过中毒字段和中毒分支RNG；P不变

玩家战斗投掷暗器：
  V > 0：x = signed16(trunc((V − W) / 2) − A)
         Δ = (A ≥ 100 或 x < 0) ? 0 : trunc(x / 2)
  V ≤ 0：Δ = trunc(V / 2) + R1 − R2  # V恰为0仍取两次RNG

AI战斗投掷暗器：
  V ≥ 0：Δ = V
  V < 0：Δ = signed16(trunc((V − W) / 2))
  # 这条路径既不读取A，也不为中毒变化额外取得R1／R2

以上进入中毒写回的分支：P' = clamp(signed16(P + Δ), 0, 99)

原版正毒普通物品先将W与V相加；原版玩家投掷却从V减去W，后者从NG1起按第4.4节改为加号。

两条原版正毒路径在中间值为负或A≥100时归零，再向零除以2。负毒普通物品与玩家投掷不读抗毒，随机差范围−4～＋4；玩家投掷的V=0也会进入这一随机分支， 普通物品的V=0则跳过整个中毒结算。

AI投掷正毒直接把V加到中毒，即使抗毒达到100也不被该能力阻止；负毒按(V−W)/2向零取整且不追加中毒随机数。

这里说的是中毒分支自身的RNG，不排除同一暗器动作另有伤害随机数。

队伍侧AI投掷还存在已核对的原版陈旧槽异常：动画和库存消耗使用当前选定物品，实际HP／伤势／中毒载荷却从最近一次有效玩家物品确认槽读取；

敌方AI仍从当前来源槽读取。因此AI公式中的V是实际载荷物品的add_poison，不一定是本次显示或消耗的物品值。
