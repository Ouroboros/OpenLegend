字段 experience

字段定义

experience：人物经验。取值来源：通关TOML中的角色实际值；未入队角色读取当前RANGER基线。

字段中文名称下一周目值边界与说明
experience 人物经验 直接继承实际累计经验，不按周目夹值 不设由周目等级节点推得的经验上限；升级仍按E(L)递推。

人物等级的原始门槛与对照节点见level字段页；经验字段不随周目封顶。

经验递推与对照节点

n为当前周目（NG1为1），Lref(n)仅为既有周目比较表的等级节点，绝非等级上限；E(L)为等级L对应的累计经验门槛，原版范围内读取原始表，超出原始表时依下文递推。

对照节点的经验门槛 = E(Lref(n))  # 不限制人物累计经验

原表所列的取值、继承及状态以本页为唯一字段定义；跨字段计算见本页下方原文或相关字段页，不在主页重复公式。

1.4 人物升级需求

原始等级与经验门槛从游戏定义读取；原版当前数据中的30级、52000、4350及拟合倍率只用于说明与核对，不是运行时代码常量。

L0 = 原始经验门槛表支持的最高等级
E0(L) = 原始门槛表中等级L的累计经验
E(L) = E0(L)，L在原始门槛表定义域内
D0(L) = E0(L＋1)－E0(L)，L=1…L0－1             # 原表每级升级费用
r = exp(对点(L, ln D0(L))做最小二乘直线拟合所得斜率)   # 原表每级费用的增长倍率，须大于1
Dlast = D0(L0－1)                               # 原表最后一级费用
周目对照节点 Lref(n) 按等级字段页的原式计算，不用于限制升级
L≥L0时：
实际升级费用 D(L) = Dlast×r^(L－L0＋1)           # 从原表末级费用起逐级乘r，在L0处连续
累计门槛 E(L) = round(E0(L0)＋Dlast×r×(r^(L－L0)－1)÷(r－1))，L＞L0
第n周目（n≥2）两个相邻对照节点之间的需求（不要求从此等级起步或在终点停止）：
C(n) = E(Lref(n))－E(Lref(n－1))

程序用原始门槛表全部等级的每级升级费用，拟合费用逐级增长的倍率，再从原表最后一级费用起按同一倍率逐级增长；延伸曲线反映整张原表的增长趋势，在原表末级处连续。倍率在运行时计算，累计门槛取整按四舍五入。

对照节点间隔来自原始表与既有CFG步长；同一role_level_step仍供既有敌方等级周目增长公式使用。下面的派生数字只是把默认门槛和每个对照窗口30级代入公式的结果；既不是每周必须支付的固定额，也不是升级停止条件。实际升级费用始终读取当前等级的D(L)。

原版当前数据核对值（仅用于说明，不得硬编码）：
L0=30，E0(30)=52000，Dlast=4350，r≈1.1524
role_level_step=30
代入后：
D(L)=4350×1.1524^(L－29)，L≥30
E(60)=2339895，E(99)=587338008

1.5 战斗经验倍率

Bbase = 原版一周目倍率的百分数数值（100表示100%）
B2 = battle_experience_ng2_percent
Bstep = battle_experience_later_step_percent

e0 = 原版按分配规则计算的该人物本场经验
B(1) = Bbase
B(n) = B2＋(n－2)×Bstep，n≥2

人物战斗经验 X = floor(e0×B(n)÷100)

原版当前值与默认CFG：Bbase=100（100%）、B2=150（150%）、Bstep=100（后续每周增加100个百分点）。

代入后，n≥2时才可化简为B(n)=100n－50（百分数数值；表中以百分比展示）。

默认配置周目 倍率 相比上一周
NG1 100% —
NG2 150% ＋50个百分点
NG3 250% ＋100个百分点
NG4 350% ＋100个百分点
NG5 450% ＋100个百分点

使用原版当前值与默认CFG时，一周目发原经验，二周目发150%，三周目发250%，四周目发350%，之后每周再加100个百分点。

它不是“上一周再乘1.5”。e0必须来自当前游戏定义中的整场经验和原分配规则，B2与Bstep必须来自CFG；程序不能按战斗ID或周目写死结果。

1.6 战斗经验与对照区间所需场数

WAR(w) = 从当前WAR.STA定义读取的战斗w整场经验
R(w,n) = floor(WAR(w)×B(n)÷100)
N(w,n) = ceil(C(n)÷R(w,n))

先把这场战斗的原经验乘本周倍率，再用两个周目对照节点之间的总需求除以单场经验并向上取整。右侧场数只表示假设从区间起点开始、仅重复同一战斗到区间终点的比较，不限制实际人物等级或经验；多人存活时还要先按原规则分经验。

单元格格式：该周整场经验／从上一对照节点练到本对照节点所需场数。所有原经验均从WAR.STA读取；列头百分比来自默认CFG，任何周目都允许越过对照节点继续升级。
