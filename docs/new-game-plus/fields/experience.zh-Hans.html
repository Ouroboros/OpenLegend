字段 experience

字段定义

experience：人物经验。取值来源：通关TOML中的角色实际值；未入队角色读取当前RANGER基线。

字段中文名称下一周目值边界与说明
experience 人物经验 直接继承并clamp 上限读取本周等级上限对应的累计门槛。

共享上限表归属字段 level；本字段的独立转移记录见上表。

本周经验合法上限

经验上限 = E(Lcap(n))

原表所列的取值、继承及状态以本页为唯一字段定义；跨字段计算见本页下方原文或相关字段页，不在主页重复公式。

1.4 人物升级需求

原始等级与经验门槛从游戏定义读取；原版当前数据中的30级、52000、4350、4200和150只用于说明与核对，不是运行时代码常量。

L0 = 原始经验门槛表支持的最高等级
E0(L) = 原始门槛表中等级L的累计经验
Dlast = E0(L0)－E0(L0－1)                # 原始最后一级费用
Dprev = E0(L0－1)－E0(L0－2)            # 原始倒数第二级费用
Sbase = Dlast－Dprev                     # 原始末段每级增量

本周等级上限 Lcap(n) 按第1.2.2节统一字段上限登记求得

L≥L0时：
实际升级费用 D(L) = Dlast＋(L－L0＋1)×Sbase
累计门槛 E(L＋1) = E(L)＋D(L)

第n周目从起始等级练到上限的需求：
C(n) = Σ D(L)，L=Lcap(n－1)…Lcap(n)－1

程序先从原始门槛表拿到最后两级各自需要多少经验，再用它们的差值继续延伸后续等级。

周目等级上限和每周新增等级数来自原始上限与CFG。下面的200250、335250等数字只是把默认门槛和默认每周增加30级代入公式后的结果；换游戏数据或等级步长时，程序必须重新计算。

原版当前数据核对值（仅用于说明，不得硬编码）：
L0=30，E0(30)=52000，Dlast=4350，Dprev=4200，Sbase=150
role_level_step=30

代入后才可化简为：
D(L)=150L
C(n)=135000n－69750，n≥2

1.5 战斗经验倍率

Bbase = 原版一周目百分比基准
B2 = battle_experience_ng2_percent
Bstep = battle_experience_later_step_percent

B(1) = Bbase
B(n) = B2＋(n－2)×Bstep，n≥2

人物战斗经验 X = floor(e0×B(n)÷100)

原版当前值与默认CFG：Bbase=100%、B2=150%、Bstep=100个百分点。

代入后，n≥2时才可化简为B(n)=100n－50%。

默认配置周目 倍率 相比上一周
NG1 100% —
NG2 150% ＋50个百分点
NG3 250% ＋100个百分点
NG4 350% ＋100个百分点
NG5 450% ＋100个百分点

使用原版当前值与默认CFG时，一周目发原经验，二周目发150%，三周目发250%，四周目发350%，之后每周再加100个百分点。

它不是“上一周再乘1.5”。e0必须来自当前游戏定义中的整场经验和原分配规则，B2与Bstep必须来自CFG；程序不能按战斗ID或周目写死结果。

1.6 实际战斗练满场数

WAR(w) = 从当前WAR.STA定义读取的战斗w整场经验
R(w,n) = floor(WAR(w)×B(n)÷100)
N(w,n) = ceil(C(n)÷R(w,n))

先把这场战斗的原经验乘本周倍率，再用“本周练满总需求”除以单场经验并向上取整。下表每格左边是这一整场给多少经验，右边是只重复这场战斗时需要打多少场；多人存活时还要先按原规则分经验。
