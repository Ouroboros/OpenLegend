字段 unassociated_manual_success_counts[ItemCount]

字段定义

unassociated_manual_success_counts[ItemCount]：无关联秘笈历史成功次数。取值来源：通关TOML中的角色实际值；未入队角色读取当前RANGER基线。

字段中文名称下一周目值边界与说明
unassociated_manual_success_counts[ItemCount] 无关联秘笈历史成功次数 完整继承并clamp 按物品ID保存无关联武功秘笈历史成功次数；上限为Lcur(n)－H0，换书、丢失、重新取得或换周目均不清零。

共享上限表归属字段 magic_levels[10]；本字段的独立转移记录见上表。

原表所列的取值、继承及状态以本页为唯一字段定义；跨字段计算见本页下方原文或相关字段页，不在主页重复公式。

无关联秘笈的历史成功次数与费用

2.1.2 无关联武功的秘笈

c = 按角色ID＋物品ID读取的隐藏成功次数，初始为0
H0 = 原版无关联武功秘笈首次费用阶级
H = c＋H0
C = need(i)×A(iq)×H
H≥Lcur(n)时不能继续完成
成功后 c = c＋1

无关联武功秘笈使用持久化隐藏阶级。程序从物品定义读取need(i)，从角色与物品组合读取c。

原版当前H0=2，所以第一次用2、第二次用3、再下一次用4；换书或换周目都不能重置。

  • 第一次使用H0，成功后依次使用H0＋1、H0＋2……；原版当前值对应2、3、4、5……。
  • 隐藏次数按角色与物品ID分别保存。换书、丢失、重新取得、物品归属重置和跨周都不清零。
  • 隐藏阶级与武功等级使用同一Lcur(n)。原版当前H0=2、M0=10，所以NG1最多成功8次；后续每周新增档数读取martial_level_step， 默认10档。
  • 永久属性每次成功只应用原物品字段一次，不随周目放大，并限制到对应玩家字段的本周上限。
