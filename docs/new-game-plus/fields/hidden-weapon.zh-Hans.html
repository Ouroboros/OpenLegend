字段 hidden_weapon

字段定义

hidden_weapon：暗器技巧。取值来源：通关TOML中的角色实际值；未入队角色读取当前RANGER基线。

字段中文名称下一周目值边界与说明
hidden_weapon 暗器技巧 直接继承并clamp 本周正常上限Cap(hidden_weapon,n)按NG1基值与运行时CFG的hidden_weapon_cap_step计算。

原版范围与本周上限

字段NG1原版基值／有效域本周NG+上限来源默认CFG与状态
hidden_weapon

NG1正常上限100；原版升级与秘笈修炼封顶100；升级证据、 修炼证据。不据此否定原版个别写入路径的越界值。

Cap(hidden_weapon,n)由NG1正常上限加上(n－1)×hidden_weapon_cap_step求得；步长从运行时CFG读取，不把最终上限直接当配置项。

NG2+继承、升级和秘笈修炼中暗器技巧的正常封顶均读取该本周上限，不再固定用原版100。

 提供的默认CFG：hidden_weapon_cap_step=100点／新增周目；NG1为100、NG2为200、NG3为300。100n仅是采用这套默认CFG时的计算结果。

本周合法上限公式

Cap(hidden_weapon,n) = NG1正常上限(hidden_weapon) + (n − 1) × hidden_weapon_cap_step

4.4 玩家投掷带毒暗器时技巧项的全周目改号规则（已确认）

这是相对原版玩家投掷机器减号 的明确新规则，从NG1起适用于所有周目。

定位到src/battle/battle_setup.cpp原有if (item_poison > 0)分支： 只把item_poison - actor.hidden_weapon中的暗器技巧前减号改成加号，

即V − W改成V + W；此条件来自原代码，不是另加的“正毒”规则。

减目标抗毒的减号及其他步骤不变。原版汇编事实见 物品毒值字段页； 不能把本节新规则反称为原版行为或笔误修复。

普通物品、AI投掷和玩家投掷V≤0的中毒分支不改。

V = item.add_poison > 0，W = actor.hidden_weapon，A = target.anti_poison
x = trunc((V + W) / 2) − A  # 原版机器在W前是减号；全周目均改为加号
Δ = (A ≥ 100 或 x < 0) ? 0 : trunc(x / 2)
# x、Δ与后续中毒状态结算一律使用检查溢出的signed 64位逻辑数值

保留第一次除以2、减目标抗毒、A≥100直接阻止新增中毒、负中间值归零及最后再次除以2的顺序；不是V + trunc(W/2) − A，也不取消原版抗毒硬门槛。

暗器技巧W读取当前角色64位值，其本周上限按第1.2.2节的运行时CFG增量计算。

例：V=80、W=100、A=0、原有中毒0时，原版机器理论增量0，新规则为45，NG1按正常上限写回45；A=100时仍增加0。

NG1投掷中毒的正常上限仍为99，但不在运行期保留原版16位回绕；NG2+使用同一64位加号公式和原版抗毒条件，本周中毒上限的具体写回方式仍须另定。

只有保存到Legacy时才验证待编码角色数值的16位范围；新TOML保留合法64位值。
