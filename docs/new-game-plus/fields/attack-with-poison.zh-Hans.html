武功带毒：原版结算路径

武功附毒（原版HP伤害分支）

attack_with_poison是角色的永久属性：物品效果标签称「功夫帶毒」，本稿称「武功带毒」；不是主动用毒的use_poison，也不是目标的当前poison。

原版两页人物状态均不显示其数值。当前原版物品定义中，成功修炼神木王鼎（ID 65，关联武功ID 27）每次增加5，含沙射影（ID 90，无关联武功）每次增加2，修炼成功后夹到0～100。

NG1关联武功达到10级后神木王鼎不能再完成修炼：正常未学且空槽熟练度为0时，首次成功学会武功也增加5，此后最多再成功9次，因此仅靠它从0最多增加到50；已有足够初值且满足修炼条件时才可能到100。

NG1正常域：level_index = unsigned16(角色对应武功熟练度) ÷ 100  # 0～9
MagicAttack = 当前武功定义的 attack[level_index]
C = actor.attack_with_poison
A = target.anti_poison
P = target.poison
PoisonPower = C + MagicAttack

若 A < 90 且 PoisonPower > A：
  Δ = trunc((PoisonPower − A) ÷ 15)  # 本次理论增加量，不是最终中毒值
  P' = signed16(P + Δ)
  若 P' > 100：P' = 99
  若 P' < 0：P' = 0
  target.poison = P'
否则：Δ = 0，target.poison 保持P

武功附毒在原版武功HP伤害、内伤写回后结算，不为附毒额外取随机数。这里的MagicAttack取角色已学武功的熟练度等级在武功定义中的攻击值， 不是本次实际HP伤害、总攻击力、物品add_poison，也不随本次内力不足导致的HP伤害威力降档改变。

原版这条分支不要求C大于0，也不检查武功定义是否另标“有毒”；A≥90直接阻止附毒，A<90时差值每满15点才增加1点。

只有通过门槛时才按有符号16位写回并依次处理超过100→99、负值→0；恰好100保留，门槛不通过则原有中毒保持不变。
