中毒

字段与范围

poison为当前中毒量，表示毒入几成；换周目清0，320名原版角色初值均为0。

从NG1起各周目的正常范围固定为0～99；取消poison_cap_step，中毒上限不随周目增加。原版武功附毒可恰好写出100，这是机器事实；NG+各施毒路径以“最深”封顶，最深不超过99，不再写出100。

上毒公式见下方上毒，毒发见回合毒伤，解毒见解毒章。武功附毒与主动施毒已接入共用毒模型，溢出可致死、不额外增加内伤，并单独追加伤血飘字。回合毒发及菜单／战斗共享解毒疗效已接入；正毒物品／暗器仍待接入。

上毒

理论每次沿用原版各路径的差值公式；最深表示抗毒抵消后还剩几成毒性，不超过99。中毒量已达最深时实际毒入为0，原有中毒量不降低，理论每次全部计为溢出，当场伤血不超过该毒停在最深时毒发一轮的伤害。取消原版抗毒90、100的固定门槛，只比较实际毒力与实际抗毒。

回合毒伤

每轮毒伤 = max(trunc(中毒量 / 10), trunc(最大生命 × 中毒量 / 1000))
target.hp = max(0, target.hp − 每轮毒伤)

符合回合结算资格时结算；资格条件与“先内伤后中毒”的顺序沿用原版。最大生命不超过100时与原版每满10点扣1点相同；超过100后按比例计算，满毒每轮约扣10%最大生命。例如中毒99时，最大生命32的主角扣9，最大生命716的欧阳锋扣70。扣血按最大生命计算，与剩余生命无关；抗毒只参与施毒，不在扣血时再次抵减。

毒发可以致死；生命降至0时按游戏死亡流程处理。运行时在本轮等待结束后、下一角色行动前检查存活状态，移除死亡角色的占位并进入相应胜负流程。整个回合的状态计算全部成功后提交，失败保留全部角色；重复角色槽仍按槽位顺序累积。原版武功附毒“恰好100保留”的边界由新施毒规则自然消除。

NG1玩家投掷带毒暗器另按已定技巧项改号； 主动用毒、 武功附毒、 物品／投掷的原版机器依据见对应字段页。 主动用毒距离按NG1用毒能力基值100封顶；AI投掷正毒暗器采用上方统一上毒公式。

用毒

字段定义

use_poison：用毒能力。取值来源：通关TOML中的角色实际值；未入队角色读取当前RANGER基线。

字段中文名称下一周目值边界与说明
use_poison 用毒能力 直接继承实际值，不按周目夹值 用毒能力不设逐周目硬上限；中毒量正常范围固定为0～99。

用毒能力与固定作用距离

原版用毒能力正常上限为100；旧方案的100 + (n − 1) × use_poison_cap_step（默认步长100）不再作为NG+角色用毒能力的周目上限，也不用于继承或增长夹值。

曾入队角色换周目时完整继承自己的实际use_poison；未入队角色读取当前RANGER基线。用毒实际能力即主动用毒的毒力，按上毒结算；作用距离仍沿用独立的原版100点封顶，不将距离封顶反写到角色用毒值。

升级与秘笈修炼已取消用毒值的100封顶；主动施毒已接入共用毒模型，读取实际能力，距离计算单独按100封顶。

主动用毒

战斗菜单要求physical_power>10且use_poison≥20；只能对敌方施毒，行动消耗2点体力。U_NG1=100仅作原版距离分档的固定基值；U取实际用毒与100的较小值，仅用于计算距离，不改写角色属性。

U = min(actor.use_poison, U_NG1)
PoisonRange = trunc(U ÷ 15) + 1

毒力为actor.use_poison，除数为4，按上毒结算。

例如use_poison=80、目标anti_poison=40时，最深49、理论每次10，前4次各新增10，第5次新增9并溢出1。

原版对照（机器事实，不是NG+规则） 
主动用毒（sub_39A45）：新增中毒 = trunc((用毒 − 抗毒) ÷ 4)，先夹到0～99，再限制为 99 − 当前中毒量

机器证据：sub_39A45。

AI选择主动用毒目标

原版两种选目标路径在目标中毒达到固定95时跳过，并要求目标实际抗毒小于施术者实际用毒。从NG1起，两种路径都只比较实际抗毒和实际用毒，移除目标中毒量的选目标跳过条件。

选目标的用毒条件：目标实际抗毒 < 施术者实际用毒
不按目标当前中毒量跳过

即使目标中毒已达本次施毒的最深，AI选目标也不因此跳过，随后照常按上毒结算。原版固定95仅作历史机器事实。两条AI用毒选目标路径均已取消该门槛，攻击力排序读取实际64位数值。

抗毒

字段定义

anti_poison：抗毒能力。我方曾入队角色取通关TOML实际值，未入队角色取当前RANGER基线；敌方从当前GAME DATA中的角色BASE抗毒累加每周目STEP。

字段中文名称下一周目值边界与说明
anti_poison 抗毒能力 我方直接继承实际值，不按周目夹值；敌方从基线累加STEP 抗毒增长、物品写入与继承均不设逐周目上限；敌方每增加一个周目增加一次STEP。

无周目抗毒硬上限；敌方从基线累加STEP

周目序号n从NG1的1开始；anti_poison_cap_step默认值100，单位为抗毒点数。我方实际抗毒不因周目增长而自动增加；曾入队角色直接继承实际值，未入队角色读取当前RANGER基线。

敌方抗毒每周目增加一次STEP

每次生成敌方时，以当前GAME DATA中该角色的NG1抗毒值为BASE，按下式计算：

敌方实际抗毒 = BASE抗毒 + (n − 1) × anti_poison_cap_step

例如BASE抗毒33、STEP=100，NG1／NG2／NG3分别为33／133／233；检查64位运算及字段合法域，不按周目夹值。敌方其他有STEP的字段见敌方成长总表。

当前RANGER.GRP资产中的秘笈没有抗毒加值。原版练功结算会把抗毒夹到0～100；NG+练功仅应用物品实际抗毒加值，不按周目夹值，当前原版秘笈因此不会凭空提高抗毒。原版练功汇编证据。

解毒

解毒能力字段来源与原版范围

detoxification为永久能力：通关TOML完整继承、未入队角色读当前RANGER基线；能力本身不按周目上限夹值，中毒量的正常范围固定为0～99。

原版正常域0～100，当前资产实值0～84，最高为角色2程灵素的84。

解毒公式（NG1起）

解毒能力 = max(actor.detoxification, 0)
理论解毒量 = clamp(trunc(解毒能力 / 3) + 随机数1 − 随机数2, 0, 99)   # 两个随机数依次为RNG.bounded(10)，各0～9
单次上限   = trunc(99 × 解毒能力 / (解毒能力 + 100))
实际解毒量 = min(理论解毒量, 单次上限, 目标中毒量)
目标中毒量 = 目标中毒量 − 实际解毒量

从NG1起取消原版准入门槛（中毒量超过“解毒能力＋20”时解毒量为0）；能力低时只是解得慢。两次随机取值的顺序不变，实际解毒量不超过目标现有中毒，不套用医疗的HP缺口或治伤保底。

单次上限与用毒的“最深”写法对称：能力越高越接近99，但不会达到99，所以满毒99至少要解两次；能力继续增长仍能一次解完更深的中毒。是否触及单次上限须包含随机差计算：例如解毒能力197时，理论解毒量最高为74，单次上限为65；不能忽略随机正偏移。药品解毒沿用原版普通物品负毒分支，与使用者无关，见物品毒值字段页。

战斗菜单要求体力>50、解毒能力≥20且仅对友方生效，完成行动另耗2点体力。原版距离＝trunc(actor.detoxification / 15) + 1；NG+从NG1起，所有周目的距离统一为trunc(min(actor.detoxification, 100) / 15) + 1。100只限制距离计算，解毒疗效仍读取实际能力；菜单选格与AI共用这一距离规则。
