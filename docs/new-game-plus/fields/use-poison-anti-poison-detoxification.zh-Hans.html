中毒

字段与范围

poison为当前中毒量，表示毒入几成；换周目清0，320名原版角色初值均为0。

从NG1起各周目的正常范围固定为0～99；取消poison_cap_step，中毒上限不随周目增加。原版武功附毒可恰好写出100，这是机器事实；NG+各施毒路径以“最深”封顶，最深不超过99，不再写出100。

施毒规则（毒力、最深、理论每次、溢出当场伤血）及原版数据算例统一见武功带毒字段页；本章只写毒发与解毒。本章是设计规则，运行时代码尚未实现。

回合毒伤

每轮毒伤 = max(trunc(中毒量 / 10), trunc(最大生命 × 中毒量 / 1000))

符合回合结算资格时结算；资格条件与“先内伤后中毒”的顺序沿用原版。最大生命不超过100时与原版每满10点扣1点相同；超过100后按比例计算，满毒每轮约扣10%最大生命。例如中毒99时，最大生命32的主角扣9，最大生命716的欧阳锋扣70。扣血按最大生命计算，与剩余生命无关；抗毒只参与施毒，不在扣血时再次抵减。

原版武功附毒“恰好100保留”的边界由新施毒规则自然消除。毒发后生命为负时是否仍改为1（即能否毒死目标）尚未确定，见武功带毒字段页第7节。

NG1玩家投掷带毒暗器另按已定技巧项改号； 主动用毒、 武功附毒、 物品／投掷的原版机器依据见对应字段页。 主动用毒距离按NG1用毒能力基值100封顶；AI投掷暗器是否改用新公式尚未确定。

用毒

字段定义

use_poison：用毒能力。取值来源：通关TOML中的角色实际值；未入队角色读取当前RANGER基线。

字段中文名称下一周目值边界与说明
use_poison 用毒能力 直接继承实际值，不按周目夹值 用毒能力不设逐周目硬上限；中毒量正常范围固定为0～99。

用毒能力与固定作用距离

原版用毒能力正常上限为100；旧方案的100 + (n − 1) × use_poison_cap_step（默认步长100）不再作为NG+角色用毒能力的周目上限，也不用于继承或增长夹值。

曾入队角色换周目时完整继承自己的实际use_poison；未入队角色读取当前RANGER基线。用毒实际能力进入施毒量公式；作用距离仍沿用独立的原版100点封顶，不将距离封顶反写到角色用毒值。目标的中毒量以本次施毒的“最深”封顶，最深不超过99。

现有运行时代码中升级、秘笈修炼仍将用毒值封顶100；本页是尚未实现的NG+设计，不把代码现状当成新规则。

主动用毒

战斗菜单要求physical_power>10且use_poison≥20；只能对敌方施毒，行动消耗2点体力。U_NG1=100仅作原版距离分档的固定基值；U取实际用毒与100的较小值，仅用于计算距离，不改写角色属性。

U = min(actor.use_poison, U_NG1)
PoisonRange = trunc(U ÷ 15) + 1
毒力 = actor.use_poison
毒力 ≤ target.anti_poison：不中毒
最深     = trunc(99 × (毒力 − target.anti_poison) ÷ 毒力)
理论每次 = trunc((毒力 − target.anti_poison) ÷ 4)
实际毒入 = max(0, min(理论每次, 最深 − target.poison))
target.poison += 实际毒入
溢出 = 理论每次 − 实际毒入，按武功带毒字段页第3节当场伤血

理论每次沿用原版“差值÷4”；最深与溢出伤血的完整规则及原版角色算例见武功带毒字段页。例如use_poison=80、目标anti_poison=40时，最深49、理论每次10，前4次各新增10，第5次新增9并溢出1。

AI选择主动用毒目标

原版两种选目标路径在目标中毒达到固定95时跳过，并要求目标实际抗毒小于施术者实际用毒。从NG1起，两种路径都只比较实际抗毒和实际用毒，移除目标中毒量的选目标跳过条件。

选目标的用毒条件：目标实际抗毒 < 施术者实际用毒
不按目标当前中毒量跳过

即使目标中毒已达本次施毒的最深，AI选目标也不因此跳过；随后实际毒入为0，理论每次全部计为溢出并当场伤血。原版固定95仅作历史机器事实。现有运行时代码尚未实现。

抗毒

字段定义

anti_poison：抗毒能力。我方曾入队角色取通关TOML实际值，未入队角色取当前RANGER基线；敌方按当前GAME DATA中的角色抗毒基线与原有周目增长系数换算，不继承我方数值。

字段中文名称下一周目值边界与说明
anti_poison 抗毒能力 我方直接继承实际值，不按周目夹值；敌方按基线比例换算 抗毒增长、物品写入与继承均不设逐周目上限；敌方仍按既有周目系数增长。

无周目抗毒硬上限；保留敌方增长系数

周目序号n从NG1的1开始；旧方案的anti_poison_cap_step提供默认值100。本次取消该字段的逐周目上限，但敌方仍需按既有公式随周目增长，因此原式仅作为敌方增长系数，绝不作为我方或敌方抗毒夹值。

EnemyAntiScale(n) = 100 + (n − 1) × anti_poison_cap_step

按默认步长，NG1／NG2／NG3的增长系数分别为100／200／300（对应100%／200%／300%）；我方实际抗毒不因周目增长而自动增加。曾入队角色直接继承实际值；未入队角色读取当前RANGER基线。NG+的抗毒增加不按该系数封顶。

敌方抗毒按既有周目系数同比例增长

每次生成敌方时，以当前GAME DATA中该角色的NG1抗毒值为基准计算，不继承上一周目的敌方实际值，也不套用我方继承规则。“向上取整”指有小数部分时取不小于结果的最小整数。

敌方实际抗毒 = ceil(敌方NG1抗毒值 × EnemyAntiScale(n) ÷ 100)
不按 EnemyAntiScale(n) 对敌方实际抗毒夹值

NG1系数100得到原有基准值；例如敌方NG1抗毒值33、当周系数150时，49.5向上取整为50。敌方其他数值仍按既有周目增长规则；整数取整可能带来不足1点的误差。

当前RANGER.GRP资产中的秘笈没有抗毒加值。原版练功结算会把抗毒夹到0～100；NG+练功仅应用物品实际抗毒加值，不按周目夹值，当前原版秘笈因此不会凭空提高抗毒。原版练功汇编证据。

解毒

解毒能力字段来源与原版范围

detoxification为永久能力：通关TOML完整继承、未入队角色读当前RANGER基线；能力本身不按周目上限夹值，中毒量的正常范围固定为0～99。

原版正常域0～100，当前资产实值0～84，最高为角色2程灵素的84。

解毒公式（NG1起）

解毒能力 = max(actor.detoxification, 0)
理论解毒量 = clamp(trunc(解毒能力 / 3) + 随机数1 − 随机数2, 0, 99)   # 两个随机数依次为RNG.bounded(10)，各0～9
实际解毒量 = min(理论解毒量, 目标中毒量)
目标中毒量 = 目标中毒量 − 实际解毒量

从NG1起取消原版准入门槛（中毒量超过“解毒能力＋max(20, trunc(解毒能力 × 20 / 100))”时解毒量为0）；能力低时只是解得慢。两次随机取值的顺序不变，实际解毒量不超过目标现有中毒，不套用医疗的HP缺口或治伤保底。中毒量最多99，解毒能力约297起可保证一次清满毒，此后能力增长不再提高效果。药品解毒沿用原版普通物品负毒分支，与使用者无关，见武功带毒字段页。

战斗菜单要求体力>50、解毒能力≥20且仅对友方生效，完成行动另耗2点体力；NG1菜单与战斗共用原版解毒核心。原版距离＝trunc(actor.detoxification / 15) + 1；NG2+解毒距离是否增长仍未定；主动用毒各周目的目标距离均按NG1用毒能力上限封顶。
