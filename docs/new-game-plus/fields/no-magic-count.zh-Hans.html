无关联秘笈成功次数

字段定义

no_magic_count[ItemCount]：无关联秘笈成功次数。名称中的no_magic对应物品的magic_id=-1，表示该秘笈不关联武功；本字段按角色和秘笈物品ID累计成功修炼次数，并非已学武功数量或尝试次数。通关TOML中的历史记录跨周继承，未记录的角色初始为0。

字段中文名称下一周目值边界与说明
no_magic_count[ItemCount] 无关联秘笈成功次数 按秘笈物品ID完整继承，不按周目夹值 仅物品定义满足magic_id=-1、need_experience>0的秘笈对应位置可非零；每成功完成修炼一次加1，其他物品位置保持0。没有逐周目成功次数上限；换书、丢失、重新取得或换周目均不清零。

原表所列的取值、继承及状态以本页为唯一字段定义；跨字段计算见本页下方原文或相关字段页，不在主页重复公式。

无对应武功秘笈的成功次数与费用

2.1.2 无关联武功的秘笈

c = 本角色的 no_magic_count[item_id]，即该秘笈历史成功次数，初始为0
H0 = 原版无关联武功秘笈首次费用阶级
H = c＋H0
C = need(i)×A(iq)×H
成功后 c = c＋1  # 不以周目为由停止，费用随c线性增长

无关联武功秘笈使用持久化隐藏阶级。程序从物品定义读取need(i)，从角色与物品组合读取c。

原版当前H0=2，所以第一次用2、第二次用3、再下一次用4；换书或换周目都不能重置。

  • 第一次使用H0，成功后依次使用H0＋1、H0＋2……；原版当前值对应2、3、4、5……。
  • 隐藏次数按角色与物品ID分别保存。换书、丢失、重新取得、物品归属重置和跨周都不清零。
  • 隐藏阶级H=c＋H0不再受本周武功对照节点限制。原版当前H0=2；第1次、第20次、第80次的费用阶级分别为2、21、81，任何NG均可按同一公式逐次完成。
  • 永久属性每次成功只应用原物品字段一次，不随周目放大；除保留固定域和内伤、中毒的独立规则外，不按周目上限夹值。
