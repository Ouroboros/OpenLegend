角色解毒：原版依据与NG2+结算

中毒状态上限和回合扣血仍在中毒字段页定义。

角色解毒的跨周目统一公式（已确定）

M = max(actor.detoxification, 0)  # 当前真实解毒能力，不是CFG能力上限
P = target.poison                  # 目标当前非负中毒值
C = PoisonCap(n)                  # 本周CFG中毒上限；NG1正常为99
R1 = RNG.bounded(10)              # 0～9
R2 = RNG.bounded(10)              # 0～9，第二次调用
Tolerance(M) = max(20, floor(M × 20 / 100))
Theory = clamp(trunc(M ÷ 3) + R1 − R2, 0, C)

若 P > M + Tolerance(M)：实际解毒量 = 0
否则：实际解毒量 = min(Theory, P)
target.poison = P − 实际解毒量

原版两次随机数先于失败门槛取得；正常能力域的解毒基础量为当前解毒能力的三分之一，随机差范围−9～＋9。

NG1能力通常为0～100，容差恒为20，正常单次上限C=99；此时理论量最大为trunc(100÷3)+9=42，因此NG1正常域按统一公式结算与原版一致，恰好100的现有中毒也不预先截断。

NG2+的20%容差只随当前解毒能力增长，不读取本周能力上限或中毒上限，也不向上凑整百；失败阈值的等号可解。

成功后的解毒量最多等于目标现有中毒，不借用医疗的回血生命缺口限制或治内伤10%保底；单次理论解毒量上限始终等于本周中毒上限，不再固定为99。
