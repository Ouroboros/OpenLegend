内伤

字段与上限

hurt为当前内伤；320名原版角色初值均为0，NG1正常范围0～99；换周目清0，不等于运行期上限。

HurtCap(n) = 99 + (n − 1) × hurt_cap_step
HurtMax(n, CFG) = HurtCap(n)
B(n) = 10 × ceil(HurtMax(n, CFG) / 10)
H：角色当前实际内伤。
P：目标当前实际中毒值。
M：施救者当前非负医疗能力。
T：医疗公式的保底前治疗量。
HurtMax(n, CFG)：本周运行期内伤上限。
B(n)：内伤百分比判定的分母。
p：待比较的内伤百分比门槛。
n：当前周目序号，NG1为1。
CFG：本周生效配置。

默认hurt_cap_step=100，NG1／NG2／NG3／NG5的HurtMax为99／199／299／499，对应B为100／200／300／500。百分比门槛用B，医疗疗效用实际HurtMax，两者不可互换。

原版影响与NG+规则

从NG1起，只有以内伤为输入的门槛及指定惩罚项按本周伤势量程折算；地图移动计数、中毒条件与医疗准入各用自身规则。以下是设计规则，尚未实现到运行时代码。

内伤 H > p%：100H > pB(n)；内伤 H < p%：100H < pB(n)
每轮内伤扣HP = trunc(H / 20)；武功对伤者的增伤 = trunc(目标H / 20)
武功新增内伤 = trunc(本次计算出的伤害 / 10)
战场行动值 = max(trunc(有效速度 / 15) − floor(100H / (40B(n))), 0)
普通物品原H/2折算项 = floor(50H / B(n))

比较与折算在合法非负伤势域用有符号64位整数，不用浮点近似；严格大于／小于及H=0的原版特例分别保留。每轮扣血和武功增伤仍用绝对点数，不随上限百分比弱化。

原版机器边界与数值对照

原版世界地图每50次移动尝试（包括受阻与入场景）扫描队伍：内伤H>50或误用队伍槽号索引的中毒>50触发三项减1；剧情脚本opcode 12需H<33、中毒0且处于连续队伍前缀；试炼轮间只在前四组、主角H<50且中毒0时恢复。NG+只改变这些入口的内伤门槛。

原版菜单H>M＋20不能回血或治伤，H>75的基础回血约为M/2，失败时的核心体力结算另按原版；物品正／负回血均读取H/2，队伍医疗选择与人物状态页的生命分色为≤33／34～66／≥67；行动值为max(trunc(有效速度/15)−trunc(H/40),0)。这些固定阈值不直接当成NG+疗效。

原版武功以目标H/20增伤，在目标HP触底截断前按计算伤害/10产伤、封顶99；回合先按内伤再按中毒扣HP。投掷原版H=0／1～33／34～66／>66对应add_hp的/4／/3／/2／/1（add_hp=0则本项不变）；玩家投掷按H−trunc(HP变化/4)后夹99，AI沿自身路径写回。敌方AI原版自身H>50、队友H>40触发对应分支，旧医疗候选筛选另有M>目标H−30。

默认NG2的HurtMax=199、B=200：地图H>50%从101起触发，剧情休息H<33%仅接受H≤65，试炼轮间H<50%仅接受H≤99；满伤199的行动惩罚为2，而旧trunc(199/40)为4。NG1／NG2／NG3满伤99／199／299的行动惩罚均为2。

每轮内伤扣HP及武功增伤不按比例折算：H=199／299／499分别为9／14／24。历史AI反例M=100、H=125满足旧M>H−30选人条件，却因H>M＋20无法通过原版医疗核心；旧筛选不是NG+医疗成功条件。

若只增大字段而保留五处旧99写回，H=199者再次受伤或使用物品可能被反夹到99；这是历史审计1717d07的反例，不是NG+设计结果。玩家与AI投掷不合并为统一公式。升级清伤、战后清伤的机器依据仍独立。

中毒

字段与上限

poison为当前中毒状态，换周目清0；320名原版角色初值均为0，正常范围0～99。原版武功附毒可恰好写出100，这是机器事实，不是NG+正常上限。

PoisonCap(n) = 99 + (n − 1) × poison_cap_step
P：目标当前实际非负中毒值target.poison；扣血不区分施毒来源。
C：本周正常中毒上限，即PoisonCap(n)。
P'：武功附毒计算后、封顶前的中毒候选值。
n：当前周目序号，NG1为1。

本周正常上限来自CFG，不再固定为99；默认poison_cap_step=100，NG1／NG2／NG3／NG5依次为99／199／299／499。

回合毒伤与写回边界

PoisonHp = trunc(P ÷ 10)

符合回合结算资格时，每满10点中毒扣1点HP：P为0～9、50～59、99、100、199时，分别扣0、5、9、10、19点。抗毒只参与施毒，不在扣血时再次抵减；本式只读取实际P，不在扣血阶段改写原版100。

原版边界BUG／NG+修复（武功附毒写回）：原版P'>100才写99，恰好100错误地保留。 NG1起该路径改按本周C封顶：P'>C时写C。 默认NG1的C=99，等价于P'≥100写99；NG2的C=199，则P'≥200写199。此为设计规则，运行时代码尚未实现。

NG1玩家投掷带毒暗器另按已定技巧项改号； 主动用毒、 武功附毒、 物品／投掷的原版机器依据见对应字段页。 NG2+其他施毒路径的施毒量、距离、数值域及写回边界仍未定；本次只确定武功附毒路径的上限边界。

原版回合扣血顺序、HP边界与中毒100例外 
进入状态扣血分支：hurt > 0
  或 (poison > 0 且 hp > 0 且 physical_power > 0 且角色非隐藏)
HurtHp = trunc(hurt ÷ 20)
PoisonHp = trunc(poison ÷ 10)
HP1 = signed16(hp − HurtHp)
HP2 = signed16(HP1 − PoisonHp)
最终HP = (HP2 < 0) ? 1 : HP2  # 恰好0仍为0

有正内伤即进入；仅有正中毒时还需HP、体力大于0且角色非隐藏。原版先扣内伤再扣中毒，每次按signed16写回；最终HP恰好0保留0，负数改为1。这些原版HP边界不自动确定NG2+写回规则。

解毒

解毒能力字段来源与原版范围

detoxification为永久能力：通关TOML直接继承、未入队角色读当前RANGER基线，换周目按本周字段上限clamp；共用上限表见攻击字段页。

原版正常域0～100，当前资产实值0～84，最高为角色2程灵素的84。

解毒公式（NG1起）

M：施救者当前非负解毒能力，即max(actor.detoxification, 0)。
P：目标当前实际非负中毒值target.poison。
C：本周正常中毒上限，即PoisonCap(n)。
R1：第一次调用RNG.bounded(10)，取值0～9。
R2：第二次调用RNG.bounded(10)，取值0～9。
Tolerance(M) = max(20, floor(M × 20 / 100))
Theory = clamp(trunc(M ÷ 3) + R1 − R2, 0, C)
若 P > M + Tolerance(M)：实际解毒量 = 0
否则：实际解毒量 = min(Theory, P)
target.poison = P − 实际解毒量

两次随机取值先于原版失败门槛；等于门槛可解。容差只随当前M增长，不随中毒上限增长；理论量最多为本周C，实际量不超过P。NG1正常能力域与原版相同；若输入原版遗留的中毒100，仍按实际P=100解毒，不表示NG+武功附毒仍可产生100；不套用医疗的HP缺口或治伤保底。

战斗菜单要求体力>50、解毒能力≥20且仅对友方生效，完成行动另耗2点体力；NG1菜单与战斗共用原版解毒核心。原版距离＝trunc(actor.detoxification÷15)+1；NG2+用毒／解毒距离是否增长仍未定。

医疗

角色医疗补HP并治内伤，不解毒或提高HP上限。

H：目标治疗前的实际内伤。
M：施救者当前非负医疗能力。
Hmax：本周实际内伤上限，即HurtMax(n, CFG)。
s：实际内伤与Hmax之比；Hmax=0时取0。
f(s)：随伤势比例变化的疗效倍率。
R：同一次治疗抽取的整数0～4。
T：倍率计算出的治疗量，未应用10%保底。
Q：回血与治内伤共用的治疗量，已应用10%保底。

使用条件

战斗菜单要求体力>50、医疗能力≥20；医疗核心要求体力≥50，非战斗只调用核心。 原版核心消耗2点体力，战斗行动完成段另消耗2点。

距离＝向下取整(min(max(M,0),100)÷15)＋1，最大7。NG1医疗能力上限100；高周目能力上限由本周CFG医疗STEP决定，不增加距离。

成功条件

H ≤ M＋max(20, 向下取整(M÷5))

等于门槛可治，各周目共用。

失败条件

核心体力不足或H超出门槛：加HP和治内伤均为0。原版失败前仍抽取一次随机0～4。

医疗公式

NG1起统一使用本式；默认NG1／NG2／NG3的Hmax为99／199／299。

若 Hmax > 0：s = H÷Hmax              # 0 ≤ H ≤ Hmax
若 Hmax = 0：s = 0                   # 此时唯一合法内伤H=0
倍率 f(s) = 80% − [(80%−10%)÷2] × s² × (1＋s)
T = 向下取整(M × f(s))＋R
Q = max(T, 向上取整(M÷10))              # 回HP和治内伤共用10%保底
实际加HP＝min(max(目标HP上限−目标当前HP, 0), Q)
实际消除内伤＝min(H, Q)
治疗后内伤＝H−实际消除内伤

两项共用Q；HP满仍可治内伤。分母用实际Hmax， 不用B(n)或Hmax＋1。本页是设计，运行时代码尚未实现。

原版公式（仅供历史对照） 
原版内伤0～25：基础回血＝向下取整(4M÷5)
原版内伤26～50：基础回血＝向下取整(3M÷4)
原版内伤51～75：基础回血＝向下取整(2M÷3)
原版内伤76以上：基础回血＝向下取整(M÷2)
原版实际加HP＝min(目标HP缺口, 基础回血＋随机0～4)
原版成功治内伤＝min(H, M)

Z.DAT医疗函数证据；原版疗效不用于NG1新周目。
