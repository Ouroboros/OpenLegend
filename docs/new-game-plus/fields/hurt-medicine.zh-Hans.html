内伤

字段与上限

hurt为当前内伤；320名原版角色初值均为0，NG1正常范围0～99；换周目清0，不等于运行期上限。

HurtCap(n) = 99 + (n − 1) × hurt_cap_step
HurtMax(n, CFG) = HurtCap(n)
B(n) = 10 × ceil(HurtMax(n, CFG) / 10)
H：角色当前实际内伤。
P：目标当前实际中毒值。
M：施救者当前非负医疗能力。
T：医疗公式的保底前治疗量。
HurtMax(n, CFG)：本周运行期内伤上限。
B(n)：内伤百分比判定的分母。
伤势比例：H / B(n)，比较前不取整。
p：待比较的百分数，例如50表示50%。
n：当前周目序号，NG1为1。
CFG：本周生效配置。

默认hurt_cap_step=100，NG1／NG2／NG3／NG5的HurtMax为99／199／299／499，对应B为100／200／300／500。百分比门槛用B，医疗疗效用实际HurtMax，两者不可互换。

原版影响与NG+规则

从NG1起，只有以内伤为输入的门槛及指定惩罚项按本周伤势量程折算；地图移动计数、中毒条件与医疗准入各用自身规则。以下是设计规则，尚未实现到运行时代码。

伤势比例 = H / B(n)  # B(n) > 0；只用于比较，不先取整
内伤高于 p%：伤势比例 > p / 100；低于 p%：伤势比例 < p / 100
每轮内伤扣HP = trunc(H / 20)；武功对伤者的增伤 = trunc(目标H / 20)
武功新增内伤 = trunc(本次计算出的伤害 / 10)
战场行动值 = max(trunc(有效速度 / 15) − trunc(100 × H / (40 × B(n))), 0)
普通物品内伤折算项 = trunc(50 × H / B(n))

严格大于／小于及H=0的原版特例分别保留。每轮扣血和武功增伤仍用绝对点数，不随上限百分比弱化。

整数比较的等价写法（实现用）

在合法非负伤势域用有符号64位整数比较：高于p%等价于100 × H > p × B(n)，低于则为100 × H < p × B(n)；等于门槛时两者都不成立。不先对H / B(n)取整，也不用浮点近似。

原版机器边界与数值对照

原版世界地图每50次移动尝试（包括受阻与入场景）扫描队伍：内伤H>50或误用队伍槽号索引的中毒>50触发三项减1；剧情脚本opcode 12需H<33、中毒0且处于连续队伍前缀；试炼轮间只在前四组、主角H<50且中毒0时恢复。NG+只改变这些入口的内伤门槛。

原版菜单H>M＋20不能回血或治伤，H>75的基础回血约为trunc(M / 2)，失败时的核心体力结算另按原版；物品正／负回血均读取trunc(H / 2)，队伍医疗选择与人物状态页的生命分色为≤33／34～66／≥67；行动值为max(trunc(有效速度 / 15)−trunc(H / 40),0)。这些固定阈值不直接当成NG+疗效。

原版武功以目标trunc(H / 20)增伤，在目标HP触底截断前按trunc(计算伤害 / 10)产伤、封顶99；回合先按内伤再按中毒扣HP。投掷原版H=0／1～33／34～66／>66对应add_hp的/4／/3／/2／/1（add_hp=0则本项不变）；玩家投掷按H−trunc(HP变化 / 4)后夹99，AI沿自身路径写回。敌方AI原版自身H>50、队友H>40触发对应分支，旧医疗候选筛选另有M>目标H−30。

默认NG2的HurtMax=199、B=200：地图伤势比例>50%从H=101起触发，剧情休息伤势比例<33%仅接受H≤65，试炼轮间伤势比例<50%仅接受H≤99；满伤199的行动惩罚为2，而旧trunc(199 / 40)为4。NG1／NG2／NG3满伤99／199／299的行动惩罚均为2。

每轮内伤扣HP及武功增伤不按比例折算：H=199／299／499分别为9／14／24。历史AI反例M=100、H=125满足旧M>H−30选人条件，却因H>M＋20无法通过原版医疗核心；旧筛选不是NG+医疗成功条件。

若只增大字段而保留五处旧99写回，H=199者再次受伤或使用物品可能被反夹到99；这是历史审计1717d07的反例，不是NG+设计结果。玩家与AI投掷不合并为统一公式。升级清伤、战后清伤的机器依据仍独立。

医疗

角色医疗补HP并治内伤，不解毒或提高HP上限。

H：目标治疗前的实际内伤。
M：施救者当前非负医疗能力。
Hmax：本周实际内伤上限，即HurtMax(n, CFG)。
s：实际内伤与Hmax之比；Hmax=0时取0。
f(s)：随伤势比例变化的疗效倍率。
R：同一次治疗抽取的整数0～4。
T：倍率计算出的治疗量，未应用10%保底。
Q：回血与治内伤共用的治疗量，已应用10%保底。

使用条件

战斗菜单要求体力>50、医疗能力≥20；医疗核心要求体力≥50，非战斗只调用核心。 原版核心消耗2点体力，战斗行动完成段另消耗2点。

距离＝trunc(min(max(M, 0), 100) / 15) + 1，最大7。距离分档固定读取100，不限制NG+实际医疗能力；不按周目能力上限夹值。

成功条件

H ≤ M + max(20, trunc(M / 5))

等于门槛可治，各周目共用。

失败条件

核心体力不足或H超出门槛：加HP和治内伤均为0。原版失败前仍抽取一次随机0～4。

医疗公式

NG1起统一使用本式；默认NG1／NG2／NG3的Hmax为99／199／299。

若 Hmax > 0：s = H / Hmax            # 0 ≤ H ≤ Hmax
若 Hmax = 0：s = 0                   # 此时唯一合法内伤H=0
倍率 f(s) = 80% − [(80% − 10%) / 2] × s² × (1 + s)
T = trunc(M × f(s)) + R
Q = max(T, ceil(M / 10))               # 回HP和治内伤共用10%保底
实际加HP＝min(max(目标HP上限−目标当前HP, 0), Q)
实际消除内伤＝min(H, Q)
治疗后内伤＝H−实际消除内伤

两项共用Q；HP满仍可治内伤。分母用实际Hmax， 不用B(n)或Hmax＋1。本页是设计，运行时代码尚未实现。

原版公式（仅供历史对照） 
原版内伤0～25：基础回血＝trunc(4 × M / 5)
原版内伤26～50：基础回血＝trunc(3 × M / 4)
原版内伤51～75：基础回血＝trunc(2 × M / 3)
原版内伤76以上：基础回血＝trunc(M / 2)
原版实际加HP＝min(目标HP缺口, 基础回血＋随机0～4)
原版成功治内伤＝min(H, M)

Z.DAT医疗函数证据；原版疗效不用于NG1新周目。
