字段 use_poison

字段定义

use_poison：用毒能力。取值来源：通关TOML中的角色实际值；未入队角色读取当前RANGER基线。

字段中文名称下一周目值边界与说明
use_poison 用毒能力 直接继承实际值，不按周目夹值 用毒能力不设逐周目硬上限；中毒状态另有独立周目上限。

用毒能力与固定作用距离

原版用毒能力正常上限为100；旧方案的100 + (n − 1) × use_poison_cap_step（默认步长100）不再作为NG+角色用毒能力的周目上限，也不用于继承或增长夹值。

曾入队角色换周目时完整继承自己的实际use_poison；未入队角色读取当前RANGER基线。用毒实际能力进入施毒量公式；作用距离仍沿用独立的原版100点封顶，不将距离封顶反写到角色用毒值。目标的中毒状态仍受本周中毒上限约束。

现有运行时代码中升级、秘笈修炼仍将用毒值封顶100；本页是尚未实现的NG+设计，不把代码现状当成新规则。

主动用毒

战斗菜单要求physical_power>10且use_poison≥20；只能对敌方施毒，行动消耗2点体力。U_NG1=100仅作原版距离分档的固定基值；U取实际用毒与100的较小值，仅用于计算距离，不改写角色属性。

U = min(actor.use_poison, U_NG1)
PoisonRange = trunc(U ÷ 15) + 1
ActivePoison = trunc((actor.use_poison - target.anti_poison) ÷ 4)
ActivePoison = clamp(ActivePoison, 0, PoisonCap(n) - target.poison)
target.poison += ActivePoison

PoisonCap(n)为本周中毒上限；例如use_poison=80、目标anti_poison=40时，未触及上限前新增10点。

AI选择主动用毒目标

原版两种选目标路径在目标中毒达到固定95时跳过，并要求目标实际抗毒小于施术者实际用毒。从NG1起，两种路径都只比较实际抗毒和实际用毒，移除目标中毒量的选目标跳过条件。

选目标的用毒条件：目标实际抗毒 < 施术者实际用毒
不按目标当前中毒量跳过

即使目标中毒已达保留的本周中毒上限，AI选目标也不因此跳过；随后主动用毒实际写入仍须按PoisonCap(n)封顶，可能增加0点。原版固定95仅作历史机器事实。此变更不修改施毒量与写回公式；现有运行时代码尚未实现。
