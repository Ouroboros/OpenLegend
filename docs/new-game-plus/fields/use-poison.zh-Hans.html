字段 use_poison

字段定义

use_poison：用毒能力。取值来源：通关TOML中的角色实际值；未入队角色读取当前RANGER基线。

字段中文名称下一周目值边界与说明
use_poison 用毒能力 直接继承并clamp 使用本周字段上限Cap(use_poison,n)。

本周角色用毒能力上限

Cap(use_poison,n) = 100 + (n − 1) × use_poison_cap_step  （n≥1）

100为NG1用毒能力的正常上限；use_poison_cap_step是运行时CFG中每新增周目的上限增量，提供的默认值为100。按此默认值，NG1／NG2／NG3上限分别为100／200／300；配置其他步长时以公式为准。

曾入队角色换周目时继承自己的实际use_poison并限制在0～Cap(use_poison,n)，上限扩大不自动增加实际值；未入队角色读取当前RANGER基线，不因上限扩大而改写。此上限不替代主动用毒的施毒公式或目标的中毒上限。

现有运行时代码中升级、秘笈修炼仍将用毒值封顶100；上述NG+上限尚未实现。

主动用毒

战斗菜单要求physical_power>10且use_poison≥20；只能对敌方施毒，行动消耗2点体力。U_NG1指上文NG1用毒能力上限；U取实际用毒与该上限的较小值，仅用于计算距离，不改写角色属性。

U = min(actor.use_poison, U_NG1)
PoisonRange = trunc(U ÷ 15) + 1
ActivePoison = trunc((actor.use_poison - target.anti_poison) ÷ 4)
ActivePoison = clamp(ActivePoison, 0, PoisonCap(n) - target.poison)
target.poison += ActivePoison

PoisonCap(n)为本周中毒上限；例如use_poison=80、目标anti_poison=40时，未触及上限前新增10点。
