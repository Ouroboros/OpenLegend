4.3 原版施毒与抗毒路径（机器事实）

以下只审计原版不同来源的施毒增量与抗毒门槛：主动用毒、武功附毒、普通物品与玩家／AI投掷各走独立路径。

玩家投掷带毒暗器时技巧项的原版减号仅是机器事实，NG1起的正式改号规则见第4.4节；各路径抗毒条件保留，不把原版封顶99直接当成NG2+已批准的写回公式。

原版主动用毒目标距离为trunc(actor.use_poison÷15)+1；角色解毒与中毒回合扣血的正式规则见第4.2节。

主动用毒

ActivePoison = trunc((actor.use_poison - target.anti_poison) ÷ 4)
ActivePoison = clamp(ActivePoison, 0, 99 - target.poison)
target.poison += ActivePoison

主动用毒先用施毒者的use_poison减去目标的anti_poison，每剩余4点差值才增加1点中毒。

抗毒等于或高于用毒时结果为0；目标已经接近99时，只补到99，不会溢出。

例如use_poison=80、目标anti_poison=40时，理论增加10点；若目标已经有95点中毒，实际只增加4点。

武功附毒的字段来源、毒力、抗毒比较与原版算例见 武功带毒字段页。

普通物品与玩家／AI暗器各自的毒性载荷和抗毒条件见 物品毒值字段页。

  • 主动用毒在战斗菜单中的条件为physical_power>10且use_poison≥20，只能对敌方生效，完成行动消耗2点体力。

本页保留主动用毒的原版公式；其他施毒路径见对应字段页。各路径抗毒条件保持原版，玩家投掷正毒的技巧项从NG1起另按第4.4节改号。NG2+其他施毒量、距离和写回细节并未据此确定；已确认的中毒扣血、正常中毒上限来源及角色解毒结算见第4.2节。
