字段 magic_levels[10]

字段定义

magic_levels[10]：武功熟练度。取值来源：通关TOML中的角色实际值；未入队角色读取当前RANGER基线。

字段中文名称下一周目值边界与说明
magic_levels[10] 武功熟练度 完整继承并clamp 逐槽限制到本周武功熟练度上限。

原版范围与本周上限

字段NG1原版基值／有效域本周NG+上限来源默认CFG与状态
magic_levels[10]、unassociated_manual_success_counts[ItemCount] 当前M0=10、H0=2；NG1隐藏成功次数最多8。 分别不超过Lcur(n)和Lcur(n)－H0；修炼结算见第2.1节。 martial_level_step=10，NG2上限20／18；已确认配置示例。

本周合法上限公式

Lcur(n) = M0 + (n − 1) × martial_level_step

原表所列的取值、继承及状态以本页为唯一字段定义；跨字段计算见本页下方原文或相关字段页，不在主页重复公式。

关联武功秘笈的本周熟练度与费用

2.1.1 有关联武功的秘笈

Lfirst = 原版未学会武功参与费用计算时的起始显示等级
L = 当前显示等级；未学会时取Lfirst
C = need(i)×A(iq)×L
L≥Lcur(n)时不能继续完成

程序从物品定义读取need(i)，从角色读取资质与当前显示等级。原版当前Lfirst=1；原始上限为10时，10→11使用系数10，之后依次使用11、12……。

  • 10→11使用显示等级10，之后依次使用11、12……。
  • 等级、熟练度和永久效果不会因为开放新上限而自动获得。
