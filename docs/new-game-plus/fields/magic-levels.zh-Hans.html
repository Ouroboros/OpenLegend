字段 magic_levels[10]

字段定义

magic_levels[10]：武功熟练度。取值来源：通关TOML中的角色实际值；未入队角色读取当前RANGER基线。每个槽保存的是熟练度数值，不保存武功等级；存档中没有独立的武功等级值。界面显示的已学等级由对应槽的熟练度换算，规则见秘笈修炼经验页。

字段中文名称下一周目值边界与说明
magic_levels[10] 武功熟练度 逐槽完整继承，不按周目夹值 熟练度与显示等级不受逐周目硬上限限制；逐槽校验存储位宽。

原版范围与周目对照节点

字段NG1原版基值／有效域NG+规则既有默认配置的对照节点
magic_levels[10] 原版武功显示等级上限M0=10。 武功熟练度和显示等级不受周目节点限制；修炼费用与换算见秘笈修炼经验页。 martial_level_step=10时，NG2对照节点为20级，不是NG2上限。

仅用于比较的周目节点

Mref(n) = M0 + (n − 1) × martial_level_step

既有表格按相邻节点比较费用和效果；martial_level_step仍供既有敌方武功等级周目增长公式使用。节点不是玩家修炼成功条件，也不作为继承或敌方战斗增长的封顶值。

原表所列的取值、继承及状态以本页为唯一字段定义；跨字段计算见本页下方原文或相关字段页，不在主页重复公式。

11级及以后武功效果成长（NG+设计）

本节整合旧评审稿第7.2～7.4、7.7～7.8节的武功效果算法，规则在此完整列出，不依赖旧稿查定义。它计算攻击威力及削减／恢复内力效果，不是秘笈修炼经验费用，也不等于最终扣血量。共用成长计算及实际HP／MP攻击已接入，11级后范围冻结、使用熟练度继续增长及64位结算已通过回归；装备周目加成、敌方成长和完整游戏链路仍待实现，进度见实现任务记录。

适用范围与原始数据

  • 1～10级直接读取当前GAME DATA中的原始效果数组，不修改原值；本节只计算11级及以后的扩展效果。
  • 输入是该武功原始十级的威力、削减／恢复内力、射程、半径、形状和基础耗内。名称和ID只用于识别、查找，不参与成长系数，不设置特例武功。
  • 已学武功的显示等级按秘笈修炼经验页的熟练度换算规则确定。换周目不自动增加熟练度或威力，也不夹到周目对照节点；继承按上方字段定义。
  • 11级及以后，射程、半径和形状固定使用该武功原10级状态。评价原始十级强度时，仍读取每一级各自的几何数据。
  • 周目号不进入效果公式。同一武功、相同实际出招等级、相同GAME DATA，在不同周目得到相同武功效果。

原始十级的综合强度

先逐级计算基本效果。内力型的0.75只用于把削减与恢复折算到同一份成长评价，不改变实际恢复内力的结算语义。

攻击型的该级基本效果 = 该级攻击威力
内力型的该级基本效果 = 该级削减内力＋0.75×该级恢复内力

对原始第1～10级分别计算：

覆盖格数：
  点攻击 = 1
  线攻击 = max(1, 该级射程)
  十字攻击 = max(1, 4×该级射程)
  面攻击 = max(1, (2×该级半径＋1)²)

多目标权重 = min(25, 1＋0.4×sqrt(覆盖格数－1))
距离权重 = 1＋0.04×max(该级射程－1, 0)
几何权重 = 多目标权重×距离权重
该级有效输出 = 该级基本效果÷几何权重
持续强度 = (第1级有效输出×第2级有效输出×…×第10级有效输出)^(1/10)

十个原始等级完全等权，均使用自己的威力与几何数据，不偏重高等级或只看原10级。25是固定校准上限，不读取当前战斗人数；上述评价也不读取敌人位置、队伍人数、战斗编号或阵型。若任一级基本效果不为正，持续强度取0，该武功不取得新增阶段增量。

耗内补偿

原10级实际耗内 = 5×基础耗内字段
耗内补偿：
  原10级实际耗内为0时，取1
  原10级实际耗内大于0时，取 min(3, (1＋原10级实际耗内÷15)^0.75)

综合强度 = 持续强度^0.6 × 耗内补偿^0.9

0.6压缩武功间的持续强度差距，0.9控制耗内补偿强度，不改变十级等权原则。零耗内武功仍可成长，但不领取耗内补偿。耗内补偿只用于成长评价，不能再乘到实际出招消耗上。

按类别计算参考中位数

攻击型与内力型分别统计。按武功类型、形状、基础耗内、附毒基准，以及威力、射程、半径、恢复内力、削减内力五组原始十级数组完全一致去重；仅十级基本效果均为正的原型参加参考统计。去重只用于计算中位数，实际武功ID不合并。

末级效果中位数 = 同类正效果原型的原10级合并效果中位数
综合强度中位数 = 同类正效果原型的综合强度中位数
阶段增量 = 末级效果中位数 × 1.25 × 综合强度 ÷ 综合强度中位数

“合并效果”在攻击型中是攻击威力，在内力型中是削减内力＋0.75×恢复内力。偶数个样本取中间两个值的平均数。参考值从当前GAME DATA重新统计，必须使用未舍入值；不能把下表显示的小数当成固定配置或公式输入。

11级后的逐级连续成长

以下公式以实际出招等级计算；10级是连续锚点，11级开始采用扩展效果。“阶段数”是超过10级后已完成的十级阶段数，“阶段内进度”在0～1之间。

阶段数 = 向下取整((实际出招等级－10)÷10)
阶段内进度 = ((实际出招等级－10) mod 10)÷10
阶段端点函数(阶段数) = 阶段数＋0.25×阶段数²÷(阶段数＋3)
平滑进度 = 3×阶段内进度²－2×阶段内进度³
等级成长进度 = 阶段端点函数(阶段数)
             ＋(阶段端点函数(阶段数＋1)－阶段端点函数(阶段数))×平滑进度
扩展合并效果 = 原10级合并效果＋阶段增量×等级成长进度

阶段内使用平滑进度连接相邻端点；10→11及20→21等边界不切换到另一条目标曲线。阶段增量是基准，不表示每十级固定增加同一个值；长期每十级实际增量趋近1.25倍阶段增量，不使用指数复利。

攻击型：
  攻击威力 = 向下取整(扩展合并效果)

内力型（原10级合并效果大于0）：
  效果比例 = 扩展合并效果÷原10级合并效果
  削减内力 = 向下取整(原10级削减量×效果比例)
  恢复内力 = 向下取整(原10级恢复量×效果比例)

原本为0的独立效果继续为0。原10级合并效果为0的武功保持零效果，不求上述比例，避免除零。中间量不提前取整，只在最终攻击威力、削减量和恢复量分别向下取整。

实际出招与数值边界

  • 保留原有内力不足时降低实际出招等级的处理。攻击威力及扩展内力效果按实际出招等级读取，不能支付低等级消耗却使用高等级威力；降低出招等级不扣已练成的熟练度。
  • 实际出招耗内仍为“出招等级除以2，向下取整，再乘基础耗内”。已学等级决定区域选级：已学1～10级读取对应原值，已学超过10级固定读取原10级区域；内力不足回退威力，不改变该区域选级规则。
  • 扩展威力仍交给既定伤害流程，不等于最终扣血／扣内，不再给武功效果额外乘周目或另叠等级伤害倍率。附毒不因为威力成长而自动扩大，按附毒字段现行规则处理。
  • 最终逻辑数值使用检查溢出的signed 64位范围，不允许Legacy 16位回绕。中间结果必须有限，不能提前用显示值舍入；校准表与算例不是存储位宽或玩法上限。
