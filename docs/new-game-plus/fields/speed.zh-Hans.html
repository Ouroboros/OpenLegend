字段 speed

字段定义

speed：轻功。取值来源：通关TOML中的角色实际值；未入队角色读取当前RANGER基线。

字段中文名称下一周目值边界与说明
speed 轻功 直接继承并验证固定域，不clamp 固定合法域0～100不随周目扩展；越界拒绝而非按周目夹值。

固定范围（非逐周目上限）

速度固定域：0～100  # 与n无关；不对跨周目继承作clamp

剧情、升级与秘笈增长保留原轻功固定范围，先用signed64检查中间量，再限制到0～100；溢出不能被后续限制掩盖。启用NG+后，普通物品的轻功结果越出0～100时拒绝整次效果并保留角色、随机状态和物品；菜单、玩家与AI共用这一检查。关闭NG+时保留原版物品能力可超过100的行为。保存与导入的轻功上界检查只在启用NG+时生效，越界拒绝而不改值；Legacy输出另按原字段16位表示范围验证。

装备add_speed另计，不乘周目数、不回写角色speed；装备后的生效速度不夹到100。详见装备生效属性规则。

当前战斗已按受检signed64求和得到生效速度，用于排序及轮首行动值。排序保留原跨槽严格比较与交换顺序，速度计算失败时不交换参战者或改写占位；不会把生效速度回写为角色轻功。实现与验收记录见实现清单。
