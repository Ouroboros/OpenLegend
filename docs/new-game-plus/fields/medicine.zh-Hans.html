医疗能力与角色医疗

角色医疗一次处理两件事：补回目标已损失的HP，减少目标现有内伤。 医疗能力是施术者的永久属性；内伤是目标的当前状态。医疗不解毒，也不增加HP上限。

使用条件

战斗菜单要求施术者体力大于50、医疗能力至少20；医疗核心在体力低于50时不执行。 非战斗医疗只调用核心。原版核心消耗2点体力，战斗行动完成段另消耗2点。

各周目的医疗距离都只按最多100点医疗能力计算： 距离＝向下取整（取当前非负医疗能力与100的较小值÷15）＋1，最大7。

NG1正常医疗能力上限是100；高周目的能力上限按本周CFG定义的医疗能力上限STEP增长。 这个STEP只决定能力可成长到多少，不直接决定本次治疗量；距离仍最多7。

成功条件

体力满足条件，且目标当前内伤不超过下方的统一门槛时进入治疗结算； 恰等于门槛仍可治。这个判断不因伤势上限提高而放宽。

失败条件

核心体力不足，或目标内伤超过统一门槛时，本次加HP为0、消除内伤为0。 原版先计算基础回血与0～4点随机值，再检查内伤门槛；不能用失败后的0倒推原版不取随机值。

医疗公式

所有周目共用同一条治疗资格公式：

目标当前内伤 ≤ 当前医疗能力
             ＋ max(20, 向下取整(当前医疗能力÷5))

原版和NG1的正常医疗能力至多100，上式的容差恒为20， 所以正好还原原版的“内伤不超过医疗能力＋20”。 NG2及之后仍代入同一算式，绝不另换一条准入公式。

从NG1起，成功治疗统一使用下方三次倍率式。 M为施救者当前非负医疗能力，H为目标治疗前内伤， Hmax=HurtMax(n, CFG)为本周内伤上限；先按治疗前数值求倍率，再抽取一次0～4的随机整数。

若 Hmax > 0：s = H÷Hmax              # 0 ≤ H ≤ Hmax，所以0 ≤ s ≤ 1
若 Hmax = 0：s = 0                   # 唯一合法内伤H=0，避免除以0
倍率 f(s) = 80% − [(80%−10%)÷2] × s² × (1＋s)

R = 同一次治疗抽取的整数0～4
T = 向下取整(M × f(s))＋R               # 先取整，再加随机值
Q = max(T, 向上取整(M÷10))              # 回HP和治内伤共用10%保底
实际加HP＝min(max(目标HP上限−目标当前HP, 0), Q)
实际消除内伤＝min(H, Q)
治疗后内伤＝H−实际消除内伤

同一个保底后治疗量用于回血和治内伤，不是把医疗能力拆给两项； 医疗能力10%的保底同时作用于两者，只在成功治疗后生效，不设内伤90以上固定治10的分支。 HP满时仍可治内伤，实际加HP受HP缺口限制，治内伤不超过现有内伤；失败时两项均为0。

默认NG1／NG2／NG3的Hmax为99／199／299，修改CFG后代入实际本周上限； 实际满伤时s=1、倍率恰为10%。伤势字段页的 B(n)=10×ceil(Hmax/10)用于其他内伤百分比门槛，本式不用Hmax＋1或B(n)作分母。 这里连续变化的是倍率；整数取整后相邻伤势可能得到相同治疗量。

原版疗效仅作机器行为对照，不再作为NG1新周目疗效：原版按绝对内伤25／50／75点分档； 成功时基础回血另加0～4随机值，治内伤直接减完整医疗能力，不使用新式10%保底。

原版内伤0～25：基础回血＝向下取整(4M÷5)
原版内伤26～50：基础回血＝向下取整(3M÷4)
原版内伤51～75：基础回血＝向下取整(2M÷3)
原版内伤76以上：基础回血＝向下取整(M÷2)
原版实际加HP＝min(目标HP缺口, 基础回血＋随机0～4)
原版成功治内伤＝min(H, M)

本设计从NG1起正式采用上述三次倍率与两项共同的10%保底； 原版档位与直接减完整医疗能力的治伤式只保留为机器行为依据，不表示运行时代码已实现新规则。 原版机器依据见Z.DAT医疗函数证据。

白话说明

NG1医疗能力20、内伤40时恰好达到资格门槛：当前内伤占上限99点的约40.4%，倍率约71.98%， 基础治疗量向下取整为14点，再加随机0～4。若HP缺口足够，回血和治内伤各为14～18点，剩22～26点内伤。

NG1医疗能力100、内伤90时两项各得24～28点、剩62～66点；内伤95时各得16～20点、剩75～79点； 满伤99时各得10～14点、剩85～89点。医疗能力81、满伤99时基础治疗量为8点， 10%保底将随机值0或1对应的治疗量提到9点，最终两项各得9～12点、剩87～90点。

NG2医疗能力200、默认满伤199时，两项各得20～24点、剩175～179点。 若医疗能力仍为100，内伤120恰好可治：两项各得59～63点、剩57～61点；内伤121则失败，两项均为0。 NG3医疗能力300、默认满伤299时，两项各得30～34点、剩265～269点。 算例均假定目标HP缺口足够；医疗能力200／300仅为试算取值，不代表医疗STEP默认值已定。
