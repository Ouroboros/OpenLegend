4.1 原版医疗与伤势机制

本节的actor是执行医疗的角色，target是接受医疗的角色；trunc表示向零取整， RNG.bounded(k)会取得0到k−1。

以下至第4.1.1节之前均为原版行为说明，不代表伤势上限或医疗能力在NG+中已经决定扩展。

原版医疗作用距离

医疗目标距离 = trunc(actor.medicine ÷ 15) + 1

医疗能力每完整增加15点，目标距离才增加1级；0～14得到1，15～29得到2，30～44得到3。

能力没有跨过下一个15点门槛时，不会提前增加距离。这是原版函数本身的算式；NG+规定的跨周目医疗距离上限见第4.1.1节。

角色解毒的原版距离见第4.2节，主动用毒的原版距离见第4.3节；不能由医疗距离自动推定它们的NG2+距离。

医疗基础恢复量

m = max(actor.medicine, 0)

若 target.hurt ≤ 25：BaseHeal = trunc(4m ÷ 5)
若 26 ≤ target.hurt ≤ 50：BaseHeal = trunc(3m ÷ 4)
若 51 ≤ target.hurt ≤ 75：BaseHeal = trunc(2m ÷ 3)
若 target.hurt > 75：BaseHeal = trunc(m ÷ 2)

伤势越重，同一医疗能力能够恢复的HP比例越低。四档依次只取医疗能力的80%、75%、约66.7%和50%；这一步只计算HP恢复量，不决定伤势减少量。

例如医疗能力为60时，目标伤势50会得到45点基础恢复，伤势51则立即降为40点基础恢复。

成功判定与最终结果

Heal = BaseHeal + RNG.bounded(5)       # 在基础值上增加0～4

若 target.hurt > actor.medicine + 20：
  Heal = 0
  本次不降低伤势
否则：
  target.hp = min(target.maximum_hp, target.hp + Heal)
  target.hurt = max(0, target.hurt - m)

医疗先按伤势档位计算恢复量，再增加0～4点随机值。随后才检查医疗能力是否足以处理当前伤势：目标伤势比医疗能力高21点或更多时，恢复HP和降低伤势都会失败；

恰好只高20点仍然成功。成功时，HP最多补到生命上限，但伤势直接减去完整的医疗能力，而不是减去折算后的BaseHeal。

原版目标HP即使已经加满，只要未触发伤势过高的失败条件，本次仍按完整医疗能力降低伤势。

这条原版说明曾见于c910dfa；它不决定NG2+尚未定稿的理论治疗量T。

例如medicine=60、hurt=50时，理论HP恢复为45～49，伤势会从50降到0；如果目标只缺20点HP，实际只补20点，但伤势仍会降到0。

若同一角色面对hurt=81，因为81大于60＋20，本次医疗完全失败；hurt=80则仍可成功。

  • 战斗菜单要求physical_power>50且medicine≥20才显示医疗可用；核心医疗计算本身在体力低于50时直接失败。也就是说，菜单条件与底层函数对体力50这个边界并不完全相同。
  • 医疗核心计算消耗2点体力，战斗共享行动尾部再消耗2点，因此一次战斗医疗通常共消耗4点体力；非战斗队伍菜单只调用核心计算时消耗2点。
  • 武功造成HP伤害后，目标增加trunc(damage÷10)点伤势并封顶99。受到39点伤害会增加3点伤势，受到40点伤害会增加4点。
  • 目标已有伤势会使本次武功伤害额外增加trunc(hurt÷20)。伤势40会让每次武功伤害再增加2点，伤势80会增加4点，因此伤势会放大后续损失。
  • 每轮行动值还会扣除trunc(hurt÷40)，所以伤势0～39没有该项惩罚，40～79扣1，80～99扣2。
  • 回合状态结算会扣除trunc(hurt÷20)点HP；伤势0～19时不扣HP，40点每轮扣2点，99点每轮扣4点。
  • 治疗物品和伤害型暗器走各自独立的物品公式，也能降低或增加hurt，最终仍限制在0～99；它们不调用上述角色医疗成功判定。

因此伤势不是单纯的显示数值：它同时降低角色医疗的HP恢复效率、提高后续武功伤害、降低行动值，并在回合结算时继续扣HP。角色医疗成功后则会同时处理HP和伤势，两种结果使用不同的计算量。

4.1.1 医疗距离、准入与治内伤规则（已确认部分）

适用边界：NG1保留上文已核对的原版角色医疗效果、失败判定、随机数及体力／伤势结算；NG2+正常伤势上限统一读取第1.2.2节登记的HurtCap(n)。

各周目的医疗目标距离另统一受NG1正常医疗能力上限约束。NG2+失败容差只随当前医疗能力增长，不随NG序号或伤势上限增长；成功后的回血与治内伤共用动态治疗量，治内伤最低为医疗能力的10%。

具体回血倍率和高NG医疗能力上限仍待确定；其他已确认的内伤关联规则见第5.4节，因此本节不是可立即实现的完整医疗规格。

伤势上限的原版基值、NG+公式与默认CFG见伤势字段页。

下方医疗失败门槛的算例，使用该字段页列出的默认CFG数值。

伤势产生、恢复和状态合法域使用本周HurtCap(n)；当前原版武功造成伤势时封顶99是NG1事实，NG2+武功产伤、回合扣血、行动值和其他内伤门槛按第5.4节已确认规则处理。

医疗准入和治内伤保底只读当前真实医疗能力及当前伤势，不因CFG上限提高而自动通过判定。

各周目医疗目标距离（已确定）

NG1MedicineRangeCap = NG1规则集的正常医疗能力上限  # 当前原版为100；跨周目固定
DistanceMedicine = min(max(actor.medicine, 0), NG1MedicineRangeCap)
MedicalRange = trunc(DistanceMedicine ÷ 15) + 1
MedicalRangeMax = trunc(NG1MedicineRangeCap ÷ 15) + 1  # 当前为7

NG1～NG999均按NG1正常医疗能力上限计算医疗距离，不随NG+医疗能力上限增加。

目前医疗能力89时距离为6，90～100时距离为7；即使当前医疗能力为1000，也先按100计算距离，最大仍为7。

仅距离计算使用截断后的DistanceMedicine；医疗失败容差、理论治疗量与成功后的10%治内伤保底仍读取当前真实医疗能力，不把100当作治疗能力上限。

原版正常NG1范围内与上文距离算式一致；超出正常范围的医疗能力在本设计中也执行距离封顶。

NG2+失败判定

M = max(actor.medicine, 0)               # 当前执行者医疗能力
H = target.hurt                          # 当前目标伤势
OriginalTolerance = 20                  # NG1原版失败差，作为规则集基准参数
ToleranceGrowthPercent = 20             # 当前确认的医疗能力增长比例
Tolerance(M) = max(OriginalTolerance,
                   floor(M × ToleranceGrowthPercent / 100))

若核心体力门槛失败，或 H > M + Tolerance(M)：治疗失败
否则：通过医疗能力与伤势门槛；等于门槛仍可治疗

两项20分别表示原版失败差20点、NG2+随医疗能力增长的20%；它们是有来源的规则参数，不是按本周目伤势上限计算的floor((HurtCap+1)×20%)。

在正常NG1医疗能力0～100内，Tolerance(M)=20；NG1实际仍走上文完整原版算法。

NG2+医疗能力100、165、166、200、400时，容差分别为20、33、33、40、80；相同医疗能力跨周目保持同一绝对治疗门槛。

保留原版核心体力低于50失败、战斗菜单体力严格大于50且医疗能力至少20的行动条件；治疗资格不代表一次能把伤势清零。

成功治疗后的共同治疗量与治内伤保底

T = 本次由医疗能力和伤势动态算出的理论治疗量   # 具体回血倍率尚未定稿
CureFloorPercent = 10                    # 规则集参数，医疗能力的10%

实际回血 = min(max(target.maximum_hp - target.hp, 0), T)
实际消除伤势 = min(H, max(T, ceil(M × CureFloorPercent / 100)))
治疗失败时：实际回血 = 0，实际消除伤势 = 0

T是同一次治疗用于回血和治内伤的共同动态计算值，不是把固定预算分成两份。

10%只为成功后的治内伤提供保底，不增加回血，也不能跨过医疗失败门槛；它不是固定治10点，更不存在伤势达到90点便固定治10点的分支。

医疗能力20、40、60、80、100时，保底分别为2、4、6、8、10点；实际回血受生命缺口限制，实际治内伤不超过现有伤势。

完整的T倍率曲线、成功但回血为0时的行动反馈以及NG2+随机数与体力结算顺序仍需明确，不能将此前拼接的平方尾段试算直接当成正式函数。
