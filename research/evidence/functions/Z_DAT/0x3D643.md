# 函数证据：`sub_3D643` `0x3D643..0x3D68A`

状态：`implemented_pending_review`

机器码在栈检查后读取 signed sprite ID；负数或大于 `0x7FFE` 返回0。合法 ID 用带符号除2序列求 pointer-table 索引，随后以传入的 signed `(x,y)` 和该帧指针调用 `sub_20354`，返回1。合法域均非负，因此现代 `legacy_sprite_index(id)` 的 `id/2` 精确保留奇偶 ID 共用同一帧：`0/1→0`、`2→1`、`0x7FFE→0x3FFF`，`0x7FFF` 拒绝；scene/world 的 `draw_sprite` 在进入共享 RLE renderer 前执行同一检查。

synthetic renderer 测试固定上述边界，真实场景六层、世界地图与结局帧固定有效资产路径。最终 REVIEW 仍需反查所有 wrapper 调用者及委托 `sub_20354`/stack-guard 边界。
