# 函数证据：`sub_3265C` `0x3265C..0x3271E`

状态：`implemented_pending_review`

映射：`openlegend::battle::BattleSetup::append_enemies`

本函数顺序扫描 WAR words33..52 的20个敌方角色 ID。仅 `-1` 表示空项；每个非-1项追加到 `word_556D2` 指向的下一个28字节参战者槽，并按下列顺序写入：

1. word0 = 敌方角色 ID；
2. word1 = 1；
3. word2/3 = WAR words53..72/73..92 的同下标 x/y；
4. word4 = 1；
5. word8 = `sub_3B1E6(current_count)`；
6. occupancy `[y*64+x] = current_count`；
7. current_count 按16位 word递增。

机器码不检查角色 ID 范围、坐标范围、重复 occupancy、参战者槽容量或 count 溢出。当前140条 WAR 记录敌方最多20人，与队伍静态成员合计最多21；所有静态坐标均在0..63。战斗93的敌方下标8与10同在 `(13,34)`，后写槽覆盖先写槽；独立 oracle 固定该原始重复格，现代实现不得去重或拒绝。
