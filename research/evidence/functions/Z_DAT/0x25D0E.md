# 函数证据：`sub_25D0E` `0x25D0E..0x25F87`

## 1. 独立机器恢复

本轮从入口恢复，不以现有 C++ 为推导输入。

- `0x25D0E..0x25D24`：系统页选择初始化为 `0`，进入重绘循环。
- `0x25D24..0x25E31`：恢复背景、绘制系统页框和三项文字，按当前选择绘制高亮并 present。
- `0x25E31..0x25E91`：等待键；上键将 `0` 回绕到 `2`，否则减一；下键将 `2` 回绕到 `0`，否则加一。处理后清对应单键态并重绘。
- `0x25E91..0x25EC8`：三确认键进入当前项，随后同时清 Enter/Space/Insert 三键态。
- `0x25EC8..0x25EF0`：选择 `0` 调 `sub_25F87(load)`；被调链返回后选择仍为 `0`，外层系统页继续显示在导入后的世界背景上。
- `0x25EF0..0x25F18`：选择 `1` 调 `sub_25F87(save)`；返回后继续系统页。
- `0x25F18..0x25F7B`：选择 `2` 显示退出确认；仅大写 `Y` 退出。非 `Y` 重绘；大写 `Y` 路径不清 `Y` 键态并进入共享清理。
- Escape 路径清 Escape 单键态并返回调用者。

输入优先级、回绕、被调后循环位置和退出清理顺序均由机器分支决定。

## 2. 汇编 → C++ 映射

- 系统页选择、回绕和 typed command：`ui::GameMenuController::handle_key`。
- 系统页 load/save/quit 分派及调用后返回页：`app::LegacyGameRuntime::handle_game_menu_result`、`perform_pending_io`、`advance_scene_effect`。
- 单键与确认键组清态：`menu_key_state_reset`、`LegacyKeyStateReset`、`LegacyKeyboard::clear_confirmation_states`。
- 大写 `Y` 退出与来源特定音乐策略：`LegacyGameRuntime::handle_key`、`handle_game_menu_result`、SDL `main`。

## 3. 差异与整轮重启

第一轮发现现代系统页上/下/Escape及确认后未按机器清对应键态。修正为显式 `LegacyKeyStateReset::{translated,confirmation_group}` 后废弃该轮结论。

第二轮从 `0x25D0E` 入口完整重审，覆盖选择保持、wait 前后返回、载入后覆盖延后恢复、非 `Y` 重绘及大写 `Y` 清理顺序，零新增差异。
