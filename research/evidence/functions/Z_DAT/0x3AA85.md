## 2. 两个32×32 pass

两pass均以signed local x为外层、signed local y为内层，各自严格覆盖32×32格。64×64索引为`(local_y+view_y)*64+local_x+view_x`；普通sprite锚点为`x=145+18*(local_x-local_y)`、`y=-81+9*(local_x+local_y)`。

1. pass1逐格读取WARFLD layer0并调用普通sprite wrapper，函数入口没有clear、fill或其他framebuffer初始化。
2. pass2逐格按固定顺序处理：path overlay → primary cursor → secondary cursor → WARFLD layer1 object → combatant/highlight → effect → damage。

现代`BattleSetup::battle_render_plan`保持相同索引、坐标、x外/y内遍历及逐格顺序；`BattleRenderer::render`保持命令顺序并以原资产执行RLE、overlay混合、高亮替色和字体绘制。

## 3. 分支、signed值与显示合同

- path range必须signed `>0`。path值仅在strict `>range`且不等于555时以CLOUD frame4、weight2绘制。primary cursor也位于该range-positive分支内：普通态frame4/weight3，alternate态frame5/weight3。secondary cursor不依赖range，但flag必须恰等于1，并以frame5/weight3绘制。
- object sprite恰为0或15000时跳过，其他值进入普通sprite wrapper。
- occupancy为signed负数时无角色。高亮要求highlight flag恰为1、effect格恰为1且role HP signed `>=0`；mode1/2/3分别将所有非透明RLE像素替换为255/47/78。高亮条件成立但mode不是1/2/3时，机器不绘高亮也不回退普通角色；HP为负则走普通角色路径。
- effect flag必须恰为1且effect格为1，sprite为`2*effect_id+frame_offset`。
- damage不要求effect可见；signed-positive kind、非负occupancy和effect格1共同进入五个独立kind equality分支。kind1..5依次格式化`-%3d,-%3d,+%3d,+%3d,-%3d`，packed颜色为`0x1014,0x3032,0x9193,0x0705,0x5053`；其他正kind不绘文字。damage anchor比普通sprite左18，纵坐标为`-141+9*(local_x+local_y)-2*offset`。
- 普通sprite `sub_3D643`与高亮sprite `sub_3D68A`均接受ID `0..0x7FFE`，以`sar/sub/sar`向零除2，故`0/1→pointer0`、`2/3→pointer1`。`sub_3D68A @ 0x3D68A..0x3D6D1`原始71 bytes SHA256=`f5db6752e76094616a48935d2eefb41454be128fba1a2c5ea5bd9b72a72550da`独立确认相同门禁；`-1`和`0x7FFF`被拒绝。

## 4. 发现、最小修正与入口重审

首轮逐块对照发现三个合法域产品差异，并分别执行最小修正：

1. 原owner不清屏，现代`BattleRenderer::render`入口却调用`framebuffer.clear(0U)`；删除该调用。
2. 原damage使用`%3d`，现代只连接无宽度十进制串；改为`decimal_text(value, 3)`。
3. 原普通/高亮sprite wrapper允许奇数ID与前一偶数共享pointer，battle专用`fight_entry`额外拒绝奇数；删除奇数门禁。

最终修正后从`0x3AA85`重新覆盖全部527条指令、58块、40分支、19次调用、两个loop tail、唯一RET及26个caller续行。地面索引/坐标、range与主副cursor、object哨兵、occupancy/HP/mode、effect公式、damage条件/宽度/符号/颜色、signed值和调用顺序未发现其他合法域差异。

现代对非法view、短path span、无效occupancy/role、未加载或损坏归档及越界asset执行确定性拒绝，替代机器裸数组/指针访问，归类平台适配；合法原始资产路径保持机器行为。
