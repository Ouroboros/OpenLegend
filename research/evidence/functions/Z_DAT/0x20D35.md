# 函数证据：`main` `0x20D35..0x20FAA`

状态：`platform_adapted`

来源：当前 `Z.DAT` 机器码；审计包 `tmp/b9-review/0x20D35.txt`

## 1. 独立机器恢复

- 入口依次初始化运行平台，分配4,000,000字节传统scratch，建立主framebuffer指针，清两个控制字、待载入槽和80字节键态。
- 初始化字体/键盘/Miles，依次载入 `3_shadow.msk`、`4_shadow.msk`，建立画面、载入共享world资源，播放music `16`，进入标题流程 `sub_20FAF`。
- 标题返回后清last-key，置主循环标志为1。每个world tick先保存当前BIOS tick并清world绘制模式。
- 输入严格单分支优先级为 left(`0x9A/0x9D`) → up(`0x9E/0x9F`) → down(`0x97/0x98`) → right(`0x99/0x9C`) → Esc奇数edge → `sub_2399E` idle。方向命中时同时清对应两字节；菜单命中时返回后清Esc edge；任何高优先级分支都会跳过本tick idle。
- 输入或scene返回之后若待载入槽不为 `-1`，先把framebuffer清为index0黑帧，调用 `sub_26208`完成载入，再清待载入槽；函数返回后同一main迭代继续world周期更新与idle-animation。这里不是标题/系统菜单的please-wait帧。
- 随后固定调用 `sub_23B3E`，仅当idle-active为1时调用world专属 `sub_23AA6`；待载入槽为 `-1` 时重绘world并present。
- present之后执行16位有符号 `(counter+1) % 5`，余数为1时旋转palette，再忙等到BIOS tick不同于本迭代入口保存值。
- 即使world系统菜单把主循环标志清零，当前迭代也不会中途退出：仍完成world周期更新、条件idle-animation、world重绘/present、palette相位和tick等待；下一次循环条件才进入shutdown。
- shutdown顺序固定为world/共享资源关闭 → music淡出 → Miles关闭 → 字体/键盘/平台恢复 → 状态0退出。

## 3. 差异与整轮重启

本函数按规则每次修正后均废弃当轮结论并从入口重启：

1. 第一轮发现编号载入的65级淡入完成后，现代先呈现一帧未执行world周期/idle-animation的画面，下一tick才更新；机器从 `sub_26208` 返回后在同一main迭代立即执行该尾链。修正 `advance_scene_effect`：非系统菜单load的淡入完成时返回主 `advance` 尾链；系统菜单load仍直接恢复覆盖页。
2. 第二轮发现world系统菜单确认退出后现代立即停止，没有机器当前迭代的最后一次world更新、重绘/present、palette相位和tick等待。加入world专用final-frame continuation：确认退出后切回裸world、标记本tick已有菜单动作以跳过idle、阻断新增输入，present完成并旋转palette后才转入exited。
3. 第三轮从 `0x20D35` 入口重新独立恢复，逐块覆盖初始化、标题调用、全部输入优先级、load尾接、world周期/idle/render、palette相位、tick等待及shutdown顺序，零新增差异。
4. 后续审计`sub_2EB49`发现scene载入槽原本应经scene通用退出和旧world回程后才到达本函数的`word_D2950`分支，现代却从菜单直接载入。补齐跨回程pending槽位并把本分支入口帧改为index0清黑后，再次从`0x20D35`入口完整复核；确认槽位分支结束后仍在同一main迭代进入`sub_23B3E`/idle/render尾链，零新增差异。
5. 启动资源owner修正后旧结论再次废弃。从入口重审确认机器调用顺序为平台/影罩→`sub_247DD`云、调色板及RANGER缓存→`sub_24C23`五层地图→标题；现代runtime成员构造现保持同一标题前失败边界，并让后续new/load/world复用缓存。其余输入、载入尾链、world周期及shutdown基本块零新增差异。

## 4. 平台适配

- DOS IRQ/BDA键态与忙等tick改为SDL event pump、显式键态对象和steady-clock tick；键码优先级、消费时点及每tick边界保留。
- 固定scratch、VGA framebuffer和手工open/close改为容器、indexed framebuffer和RAII；资源建立/释放的可观察顺序保留。
- Miles/DOS驱动替换为libADLMIDI、软件混音和SDL音频设备；music fade/delay/end以及应用退出顺序保留，PCM与实体SBPRO不宣称逐采样一致。
- 原版同步嵌套菜单/场景循环拆为宿主帧continuation；present数量、palette生效相位和输入阻断边界保留。
