# 函数证据：`sub_2EB49` `0x2EB49..0x2ED7D`

状态：`platform_adapted`

来源：当前 `Z.DAT` 机器码；审计包 `tmp/b9-review/0x2EB49.txt`；调用链 `tmp/b9-review/0x20D35.txt`、`tmp/b9-review/0x26B5E.txt` 与 `research/ida/reports/Z_DAT.pseudocode.txt` 的通用scene loop `sub_28E40`

## 1. 独立机器恢复

- 入口把framebuffer清为palette index0并执行`sub_3CD17`的65级从黑淡入；因为像素全为0，整个淡入阶段视觉上保持黑帧。随后进入四项同步菜单，初始选择0。
- 44-byte内嵌表是四个11-byte NUL结尾标签：“載入進度一 / 載入進度二 / 載入進度三 / 離開睡覺去”。主面板为`(109,40,101,90)`，四行位于`(119,45+20*i)`；普通色`0x2321`，当前项覆盖色`0x6663`，每轮绘制后present。
- `Down=0x98`按`3→0`否则`+1`。`Up=0x9E`按`0→2`否则`-1`，因此保留这个菜单独有的原BUG，不能把0向上改为3。
- `Enter=0x0D`、`Space=0x20`、keypad Insert/0 `0x96`均确认；其他键包括Esc无副作用。
- 选择0..2时先清last-key，写`word_D2954=0`与`word_D2950=slot`，结束菜单循环，并对当前菜单执行一次64级淡黑。
- 设置槽位会让外围scene loop退出。外围跳过scene保存，清last-key及八方向键态，再对仍为菜单像素的framebuffer执行第二次64级淡黑；随后恢复旧world资源，present旧world黑帧并执行65级淡入。回到`main`后，`word_D2950`分支先把framebuffer清为index0，再调用`sub_26208(slot)`；编号载入自身再执行64级黑帧淡黑、两次相同新world黑帧和65级淡入。槽位选择不能从菜单第一轮淡黑直接跳到编号载入。
- 选择3时在当前framebuffer叠加`(71,140,177,31)`确认框，并在`(75,145)`绘“真要離開遊戲（Ｙ／Ｎ）”色`0x0705`，present后同步等待任意非零键。只有大写`Y=0x59`执行资源关闭、平台shutdown和进程退出；任意其他键返回主菜单。确认框不清除，因其位于主面板外，后续主菜单重绘仍保留这些像素。

- 黑帧、65级淡入、四项状态及两种64级淡黑：`SceneSession::start_load_menu`、`advance_load_menu`、`LoadMenuState::Phase`与runtime `SceneEffectKind`。
- 标签、圆角面板、颜色、选择原BUG及残留确认框：`SceneSession::render_load_menu`、`draw_panel`、`load_menu_framebuffer_`。
- 第一轮菜单淡黑后退出scene、第二轮通用退出淡黑、方向清态、旧world黑帧/淡入：`PendingContinuation::scene_exit`、`SceneSession::resume`、`exit_transition_pending`、`LegacyGameRuntime::handle_scene_result`与`world_scene_return_pending_`。
- `main`槽位分支的清黑与编号载入：`LegacyGameRuntime::pending_scene_load_slot_`、`advance_scene_effect`、`perform_pending_io`、`LoadTransitionPhase`。
- 大写Y退出：`SceneStepKind::quit`及SDL主循环RAII shutdown。

## 3. 差异、废弃与重启

1. 第一轮从入口核对菜单局部块均一致，但扩展到`word_D2954/word_D2950`调用链后发现现代实现于第一轮菜单淡黑结束即直接`load_slot`，省略机器的scene通用退出淡黑、旧world黑帧/淡入以及`main`清黑后才载入的顺序。废弃该轮；将选中槽位附着到既有`scene_exit` continuation，第二次淡黑后以`return_world(save_slot)`返回，旧world回程完成的同一continuation再清黑并进入既有编号载入尾链。
2. 第二轮从`0x2EB49`入口重新读取，逐块覆盖黑帧淡入、四项绘制、上下分支、三确认键、槽位写集、两层scene退出、main载入链、确认框残留及Y终止，零新增差异。菜单空闲重绘在全黑底上幂等：面板边线和全部文字每轮覆盖自身非零像素，确认框又与主面板不相交。

## 4. 平台适配

- DOS同步循环、palette函数和绝对全局槽位改为SDL逐帧continuation与强类型optional；所有present、帧数、输入阻断及可见framebuffer顺序保留。
- DOS显式关闭资源/IRQ并终止进程改为RAII资源释放与SDL主循环退出；大写Y唯一确认合同保留。
- 载入失败由现代错误模态返回旧world；原机器缺少等价的可恢复错误所有权，此分支登记为平台错误适配，不改变成功路径。
