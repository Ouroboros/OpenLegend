# 函数证据：`sub_32A51` `0x32A51..0x32B78`

状态：`implemented_pending_review`

映射：`openlegend::battle::BattleSetup::sort_by_effective_speed`

函数把当前 `word_556D2` 复制为 signed 16位上界，按 `i=0..count-2`、`j=i+1..count-1` 比较。每个参战者的比较值严格为：

```text
int16(role.word44_speed
    + equipped_item_0.word53_add_speed（equipment id >= 0时）
    + equipped_item_1.word53_add_speed（equipment id >= 0时）)
```

每次加法保留16位回绕，最终按 signed 16位比较；仅当前值严格小于后值时调用 `sub_32B78(i,j)`，所以结果为降序且等值不交换。原地址证明 item array 基址为 `0xA2744`、`0xA27AE` 是 byte106/word53，与 typed `item_word::add_speed` 一致。

测试固定有效速度40/40保持 `[1,3]`，改为41/40后交换；Linux Debug 14/14。最终不限次数 REVIEW 前不标 `assembly_exact`。
