# 函数证据：`sub_32E59` `0x32E59..0x33567`

状态：`pending_implementation`

本函数是 side word=0 且自动标志为0时的玩家行动菜单。headless IDA 从 `0x55A06` 读取10个固定20字节 Big5 项：

| action id | 文案 | 可用条件 |
|---:|---|---|
| 0 | 移動 | physical_power word21 > 5 且参战者 word6 > 0 |
| 1 | 攻擊 | physical_power > 10，十个武功槽中至少一个 ID 非0，且这些武功的最小 need_mp word16 <= 当前 mp word41 |
| 2 | 用毒 | physical_power > 10 且 use_poison word47 >= 20 |
| 3 | 解毒 | physical_power > 50 且 detoxification word48 >= 20 |
| 4 | 醫療 | physical_power > 50 且 medicine word46 >= 20 |
| 5 | 物品 | 恒可用 |
| 6 | 等待 | 恒可用 |
| 7 | 狀態 | 恒可用 |
| 8 | 休息 | 恒可用 |
| 9 | 自動 | 恒可用 |

函数按 action id 建10个0/1可用表，再把 cursor 维护为“可用项 ordinal”而非 action id；每次绘制都重新扫描 ordinal 对应的原 action id。上下键在可用数量内回绕，三个确认 flag 任一命中后全部清零并按原 action id调用对应 handler。移動返回后重新检查门槛，失效时从表中移除并减少可用数。

handler 后若参战者 word7仍为0，则重建菜单、重画战场并继续；word7==1、结果 word>=1或本次 action id==6（等待）任一成立即退出。函数返回最后 action id。当前只完成独立恢复，十个动作 handler、菜单像素/present/input flag 和退出 continuation 均待实现。
