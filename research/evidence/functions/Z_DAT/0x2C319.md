# 函数证据：`sub_2C319` `0x2C319..0x2CC06`

状态：`implemented_pending_review`

机器码把 KDEF 记录读入 word 数组，令 PC `ebx=0`、执行标志 `esi=1`。每轮先检查当前 word 是否为 `-1` 或执行标志是否清零；opcode7 只清执行标志。其余 opcode 以无符号16位与67比较后进入68项跳表，各 case 按自身固定宽度推进 PC；条件 helper 的返回偏移叠加在固定宽度之后。现代 `SceneSession::run_event/resume` 保留同一终止、固定宽度、条件偏移、同步输出和 continuation 边界。

当前1,018条原资产脚本共13,315条指令、67种实际 opcode；opcode24和范围外 opcode 均不可达。opcode24 的合法跳表项调用 `sub_2EB49`，现代实现已从错误的直接 quit 修正为载入进度菜单。对于 opcode68，原机器码在 OOB 间接跳转前没有修改 PC：跳表基址 `0x2C209`，索引 dword 地址为函数入口 `0x2C319`，值为入口机器字节解释得到的 `0x00004068`。现代不能安全执行该越界代码指针，适配为保持 PC/状态并返回 `stay`；synthetic `[68,2,123,1,-1]` 固定后续加物品指令不得执行。

独立资产扫描、synthetic KDEF 与 Linux Debug BUILD 已覆盖上述合同；68个合法 case 及全部委托 helper 的最终双向逐基本块 REVIEW 尚未执行。
