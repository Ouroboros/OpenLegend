# 函数证据：`sub_20663` `0x20663..0x206AD`

状态：`implemented_pending_review`

机器码从 `base + y*320 + x` 开始，逐行读取16字节 ASCII glyph；每个置位 bit 以小端 word 写入“前景、右侧阴影”两个相邻字节。每行处理8像素后地址加312，总步长320。函数没有屏幕裁剪；`sub_3D950` 对所有 ASCII（包括 `_`）均直接取原 glyph 并固定前进8像素。

现代场景专用 `draw_dialogue_text` 使用相同直接 ASCII glyph、8像素步长和线性 framebuffer 写入；当前2,977条 TALK 没有独立 ASCII `_`，但实现仍保留机器语义。最终双向 REVIEW 尚未执行。
