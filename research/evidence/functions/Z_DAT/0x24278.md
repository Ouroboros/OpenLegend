# 函数证据：`sub_24278` `0x24278..0x24417`

状态：`platform_adapted`

来源：当前 `Z.DAT` 机器码；`research/ida/reports/Z_DAT.b6_world_xrefs.txt`。

## 1. 物理范围与调用边界

- 物理范围为`0x24278..0x24417`，415 bytes；两个直接caller分别是横向移动`sub_23C98`和纵向移动`sub_23F28`。
- 横向caller在坐标提交后传axis=0；纵向caller在坐标提交后传axis=1。两者返回后都直接检查天气标志，均不消费本函数返回值。
- 唯一业务callee为缓存总加载`sub_24CE8`；另有Watcom栈检查`sub_3ED1E(12)`。

## 2. 独立机器恢复

- axis=0计算`desired_x=clamp(world_x-64,0,352)`，只检查local X；任意非零axis计算`desired_y=clamp(world_y-64,0,352)`，只检查local Y。
- 重载条件严格为对应local坐标`>98`或`<11`，且该轴候选origin与现origin不同。local=11/98不重载；越界但候选origin相同时也立即返回。
- 命中重载后不只更新移动轴，而是按X后Y的顺序重新计算并分别限制两个origin到`0..352`，再调用`sub_24CE8(origin_x,origin_y)`。
- `sub_24CE8`无条件依次调用`sub_24D43`、`sub_24DB8`、`sub_24E2D`、`sub_24EA2`、`sub_24F17`，即EARTH→BUILDING→SURFACE→BUILDX→BUILDY五层。
- 五层重载返回后先重算local X，再重算local Y。重载路径最终`EAX`是local Y；短路路径`EAX`仍是当前轴候选origin，但两个caller均不使用。
- 本函数不写world X/Y、方向、乘船字段或RANGER header；未命中条件时不调用任何层读取函数。

## 3. 汇编 → C++ 映射

- `WorldSession::reload_cache_if_needed(vertical_move)`按同一axis选择、严格阈值和候选origin差异判断决定是否重载；`complete_move`横移传false、纵移传true，且调用发生在世界坐标提交之后、天气粒子滚动之前。
- 命中时`WorldCache::reload`接收同时从当前world X/Y派生的两个origin；其`kLayerLoadOrder`固定为EARTH→BUILDING→SURFACE→BUILDX→BUILDY，每层按128行、每行128个word复制。
- 现代local X/Y由`world-cache.origin`按需派生，重载完成后自然同时更新；机器未使用的返回值不建立现代接口。
- 逐基本块对照两个axis入口、四个严格阈值分支、origin相同短路、双origin限制、五层调用和两个local重算，未发现需要修改产品实现的差异。

## 4. 平台适配

- DOS版在每次重载时从五个文件句柄seek/read；现代构造阶段只读加载五层完整地图，重载时以相同行序复制同一原资产word。`WorldCache::reload`另有地图有效性和origin范围保护，合法会话路径恒满足。
- DOS可写origin/local全局改由`WorldCache` origin和`WorldSession`按需local派生持有；RANGER header只在明确持久化边界同步，不在成功或阻挡移动时提前写入。

- 真实资产五层cache在origin `(293,171)`的逐层FNV-1a hash固定，并验证非法origin 353被现代保护拒绝。
